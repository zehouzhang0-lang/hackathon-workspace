1. **合成榨汁杯案例统一来源。** 目标：350ml便携榨汁杯、69.9元、USB-C；播放58000、商品点击1450、加购96、下单54、支付42；图示窗口2026-08-21至2026-08-27。统筹制作并验证同一共享种子，明确单位／渠道／对象／样本与嵌套关系。仅首次资料，不预载分析、选择、执行和未来反馈；真实输入不能因叫“榨汁杯”而套模板。旧床底案例保留回归，不冒充新案例。
2. **漏斗数学正确。** 只有口径可比时才算：播放→点击转换2.5%、流失97.5%／56550；点击→加购转换约6.62%、流失约93.38%／1354。后者不是最大流失。链路区可改为“顾客在哪一步流失／本轮先验证哪一步”，优先点击→加购须有可行动性、限制与依据，不能从排序推出因果。样本口径不一致则并列展示记录与冲突，不拼漏斗。
3. **假设不等于结论。** 老板感受、AI假设、提取值、商家确认与外部核验分开；“符合”不证实根因。少量咨询不代表顾客总体比例。样本100和24—72小时是可标注的计划起点，不能承诺统计充分、显著、必然有效或因果效果。
4. **保存和执行分开。** 下载、复制、查看、选路、采用、执行、反馈、保存和读回是不同事件。默认未知、执行时间可空；已有版本与历史不能因换路、删除附件或新轮次被覆盖。
5. **反馈改变建议须可追溯。** 没变化不等于失败；做完但变差仍是done+worse，不记未执行。再判断依据实际保存记录、窗口／样本和风险，不能仅拼一句“读取过历史”而继续同一固定答案。
6. **未知能力不能冒充真实。** 当前MoneyAI健康可达不等于分析／提取／历史可用；本机规则、合成演示、实际调用的Skill、真实模型分别标识。不能伪造专家执行流水、确认OCR成功或“下次一定读回”。
7. **安全与隐私。** 截图／表格只是待分析数据，不执行公式、宏、脚本、外部链接或文件内指令。新增图片／Excel接受目标不授权外发；音频识别单独同意。分享许可、模型费用、平台操作仍未获准。
8. **过程证据。** 首屏、布局变化和主要交互可用时应提供实际运行图及尺寸。Browser可信路径阻塞继续如实登记，不改信任、不静默用Playwright，不拿四张草稿冒充完成截图。单固定标题动效、减少动效与中文键盘保护继续，手机/Figma后置。
