# 直播执行稿结构

本参考用于把已核验的话术整理为整场执行稿。阶段、时长和商品顺序由用户实际直播计划决定，不套固定时间表、商品数量、预算或品类比例。

缺失商业事实不得用占位数字替代。可以先完成不依赖它的结构，并把相关段落标为不可口播。

## 二、可组合阶段

按实际需要选用和调整：

1. **开场与议程**：说明本场范围、内容顺序和提问方式。
2. **商品信息说明**：逐项讲清规格、适用场景、已确认特点和限制。
3. **演示或证据展示**：只展示真实材料，说明演示条件与不能外推的部分。
4. **问答与异议处理**：回答已核验问题；未知问题进入待办。
5. **价格、活动与履约说明**：仅在对应信息已核验时出现，完整说明条件。
6. **总结与售后入口**：复述关键限制、结算核对和正式客服渠道。

阶段不要求固定顺序。若出现安全、价格、履约或投诉问题，应暂停原流程并优先处理。
