# 大战黑客松

本仓库用于本次黑客松的项目资料、开发代码与进度记录，便于在不同设备之间继续工作。

## 当前状态

处于赛前准备阶段，比赛规则、时间、团队情况和项目方向尚待确认。

## 从这里开始

- [项目进度](PROGRESS.md)：记录当前阶段、已完成事项、待办和重要决定。
- [多设备同步指南](docs/SYNC.md)：首次下载项目，以及切换设备时如何拉取与推送。

## 工作约定

- 每次开工先拉取最新内容，结束时更新进度、提交并推送。
- 重要决定和后续任务写入 `PROGRESS.md`，避免只保留在聊天里。
- API 密钥、令牌、密码和真实的 `.env` 文件不进入仓库；需要时只提交不含秘密的配置示例。
- 技术方案确定后，再补充代码目录、安装步骤和运行说明。
