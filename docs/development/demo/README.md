## 本轮建议的实现取舍

- 三份独立HTML，共用CSS和原生ES modules；不初始化三个React工程。功能在本地浏览器真实可交互，生成内容注明演示来源。
- 用现有Python提供同源静态页面及窄后端API；不依赖`file://`、CDN或云数据库。离线演示可独立运行，用来验证界面与本地状态；不代替MoneyAI正式工作流。
- 先真实实现文件接收/预览、受支持文本解析、页面跳转、状态保存读回、文案复制及HTML报告下载。
- 任意图片OCR、抖音后台抓取、真实统计预测未实现。MoneyAI本机安装及健康接口已验证，项目分析、决策写入和历史读回接口已划定，专用会话与调用范围未完成前明确拒绝业务发送；见[集成记录](MONEYAI_INTEGRATION.md)。REQ-25下关闭新图片入口，历史图片仍保留待核对；演示模板不能冒充实时模型输出。
- 第三页采用“只交付所选行动所需内容＋可选轻量反馈＋明确保存＋带反馈回第二页”的最小演示范围；不再追问是否应强制填反馈。
- 三页沿用同一临时视觉，边跑PC边完善；不因为V0.4已有CSS就采用其深色风格。手机与Figma专门设计在PC基础稿及主流程之后安排。
