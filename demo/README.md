# 路芽｜三页PC基础Demo

2026-08-28：三页基础代码与共享模块已落地，先让网页端形成可试用的主流程，再完善视觉和手机尺寸。**尚未完成真实浏览器验收，最终视觉未获批准。** 当前以合成案例和本地规则输出验证界面；MoneyAI是正式分析、路径与历史决策的核心载体，但业务通路仍待接入，不能把本地记录当成MoneyAI记忆。

## 启动

从仓库根目录运行：

```powershell
python -B -X utf8 server/app.py --port 4188
```

打开`http://127.0.0.1:4188/01-intake.html`。当前统筹已启动统一4188服务，其他任务不要重复启动或清理未知进程。服务只提供本目录静态文件与明确的项目API，不服务仓库根目录或私密资料。

MoneyAI本机服务地址由统筹通过`--moneyai-url`显式指定；端口会变化，不提交凭据或把发现时端口写死。未指定时仍可使用明确标注的本地演示，不据此判断MoneyAI未安装。详见[MoneyAI通路与边界](../docs/development/demo/MONEYAI_INTEGRATION.md)。

三页使用同一个来源，不能混用localhost、127.0.0.1、不同端口或file协议。IndexedDB只保存在当前浏览器配置中，不随Git同步；换设备不会自动带走资料。

## 基础走读

三页保持渐进：说清情况→选择下一步→拿内容使用；完整依据/假设等有名称的入口，不默认展开成专业三栏。品牌配色与最终UI尚未验收。

1. 第一页REQ-25语音主入口、材料次入口、折叠手动及逐步理解确认已完成本批代码接线；共享INTAKE_SET/最多三问已接入，真实语音与浏览器操作未验。共享层已修文件事实更正/确认卡失效及同ID恢复，页面恢复入口已由干净上下文替身修复交回，原首页任务已按用户要求停写；共享投影优先核对事实ID，避免新材料更正误配旧记录。提取未就绪时手动核对，原话和编辑文字都须保存后再确认问题。
2. 第二页查看路径、风险、证据、情景或不可估状态；报告下载不自动选路。明确选择后进入第三页。
3. 第三页先取用只读文案/步骤；复制或下载不记为执行。可不填反馈，也可明确记录执行与观察、保存后再开始新一轮。

页头“载入示例”是明确替换操作，不会自动加载商家。三种合成种子为`underbed_complete_v1`、`one_sentence_v1`、`scope_conflict_v1`，均没有预置分析、选择、执行或未来反馈。[标准上传样例](samples/README.md)也都是合成材料。

只读成品是当前基础范围，复杂编辑和历史稿导出未完成。CSV/JSON按白名单解析；REQ-25下关闭新图片入口，既有图片/原件/历史保留；TXT待核对，不宣称任意OCR或模型理解。缺失不补0，口径冲突不拼漏斗，假设情景不等于成功概率或行动增量。
