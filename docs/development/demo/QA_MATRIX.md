## 每页交接格式

在自己唯一的`QA_AGENT_N.md`写：负责页面与契约版本、修改文件、启动来源、已运行命令/操作、结果、截图位置、未检查项、问题与共享模块变更请求。引用真实存在的文件；不要先写不存在截图的Markdown链接。

统筹最终检查：三页全部接同一状态API/样式；没有各自的localStorage键、不同合成商家、偷改共享文件或硬编码成功状态。实际验收记录与此待执行矩阵分开。

当前已有验证命令`python scripts/verify_demo_content.py`与`git diff --check`只检查仓库素材、文档链接和文本格式；它们不能替代D01—D18。未来共享模块可使用Node内置测试，DOM/IndexedDB、下载与跨页仍须在浏览器验证。
