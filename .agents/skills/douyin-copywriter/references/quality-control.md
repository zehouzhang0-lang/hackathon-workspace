# 文案质检、查重与风险控制

优化、批量、查重、商业推广和高风险声明任务必须使用本文件。普通生成也应遵守“事实边界”和“标题兑现”两项硬约束。

## 发布前检查

按顺序检查并直接修正：

1. **事实边界**：数据、价格、时间、库存、资质、身份、案例、产品效果、引用和群体比例是否来自用户材料或可靠来源。
2. **承诺兑现**：标题与开场承诺的内容，是否在正文中明确交付。
3. **受众与场景**：观众能否快速判断“这和我有什么关系”。
4. **信息增量**：每一段是否推进观点、步骤、例子或情绪，而非重复上一句。
5. **口语可读**：是否存在过长句、书面连接词、绕口数字、空泛开场或连续口号。
6. **长度与时长**：口播字数是否与目标时长大致匹配；信息点是否过密。
7. **CTA 克制**：是否只有一个主要动作，且动作与内容价值自然衔接。
8. **版本差异**：批量候选是否改变策略，而非只换同义词。
9. **语气与关系**：是否包含羞辱、恐吓、操控、恶意攀比、冒充用户或对负面评论的攻击。
10. **平台与领域风险**：是否含绝对化效果、虚假稀缺、未经证实的医疗健康、法律或金融结论。

默认静默修正可确定的问题。只有事实待补、结论需验证或风险会改变用户是否能发布时，才在成品后列“发布前需确认”。

## 事实与时效处理

- 用户提供的资料内部冲突时，不自行选一个版本；标出冲突并请求确认。
- 涉及当前政策、平台规则、实时热点、价格、活动、医学、法律或金融信息时，如果宿主平台有可靠搜索或知识库并允许使用，应先核实；否则明确标记待确认。
- 不生成假见证、假测评、假销量、假专家身份、假用户评论或无法证明的“第一”“唯一”“100%有效”。
- 合理保留用户的营销力度，但把不可证明的强承诺改为可观察、可限定的表达。

## 标题吸引力评估

没有真实发布数据时，不给点击率预测。用户要求评分或比较时，可对每项按 1–5 分做启发式评估：

| 维度 | 评估问题 |
|---|---|
| 清晰度 | 是否一眼知道主题或问题 |
| 相关性 | 目标人群是否会认为与自己有关 |
| 具体度 | 是否有具体场景、步骤、结果或范围 |
| 可信度 | 承诺是否被素材和正文支持 |
| 好奇度 | 是否存在合理信息差但不故弄玄虚 |
| 正文匹配 | 点开后是否能得到标题承诺的内容 |

评分必须标注为“文案启发式评估”，不是平台预测。最后给可测试假设，不宣布实际赢家。

## 查重与降重

### 先声明检测范围

根据实际资源选择一种范围：

1. **仅当前文本**：检查内部重复、套话密度和多个版本之间的相似；
2. **用户提供语料**：与给定参考文案逐段比较；
3. **外部工具或检索结果**：只按工具实际返回的匹配范围说明，不扩大成全网结论。

没有外部语料或工具时，禁止输出“全网原创率 XX%”。如果用户必须要分数，只能给明确标注的“内部改写风险”低、中、高，或说明启发式方法和样本范围。

### 检测步骤

1. 抽取核心观点、独特事实、结构顺序和高辨识度短语；
2. 标出连续重复表达、模板化钩子、同一比喻、相同论证顺序和只换同义词的段落；
3. 区分不可避免的领域术语与可改写的创意表达；
4. 给每处风险说明原因；
5. 通过改变观察角度、信息顺序、例子、句法和叙述者立场重写，而不是机械替换近义词；
6. 复查重写后是否仍保留用户事实、原意、关键词和行动目标。

### 默认查重交付格式

```markdown
【检测范围】仅当前文本／与所给语料比较／工具覆盖范围
【整体风险】低／中／高
【疑似重复或模板化片段】
- 片段：……
  原因：……
  改写方向：……
【改写版】
可直接使用的完整新版
```

## 商业推广检查

- 产品利益必须能由功能、成分、服务流程或真实案例支撑。
- 价格、优惠、赠品、库存、限时和名额必须来自用户确认；缺失时用占位符。
- 避免用恐惧、羞耻或身份焦虑逼迫购买。
- 不冒充消费者发布评价，也不指导刷评论或虚构互动。
- 对效果因人而异的产品，保留必要条件、使用场景和边界，不以小字免责声明掩盖主文案的强承诺。

## 高风险领域

健康、医疗、法律、金融、安全等内容优先做通俗表达而非个案指令。若缺少可靠资料：

- 不补写诊断、疗效、收益、法律结论或保证；
- 明确哪些句子需要专业审核或来源；
- 将绝对结论改成信息性描述和一般注意事项；
- 在不影响主体文案的前提下加入适当边界说明。

## 最终交付原则

质检不是额外写一篇报告。除非用户要求审计，最终回复仍以可直接使用的成品为主；风险说明应短、具体、可行动。
