## 资料接收与真实处理

- 点击选择或拖入本轮支持的TXT/CSV/JSON时真实接收File/Blob；没有图片理解前关闭新图片上传/截图粘贴入口，旧图片原件仍可真实预览，不是只显示文件名。
- 只处理用户触发的文字粘贴；不主动读取剪贴板、不劫持普通文字粘贴。截图粘贴明确提示本轮暂不接收；取消文件选择不能清掉已有资料。
- 类型、数量、体积上限与持久化方式按共享契约；不支持的格式明确说明，不假装解析。重复添加按契约去重或提示。
- 既有历史图片状态用“已接收，内容待核对”；没有 OCR 时不显示“已识别金额/订单”，不能用演示答案伪装对任意图片的识别。
- 对共享标准示例 CSV/TXT/JSON 做真实读取与解析，展示实际读取值及来源位置；普通 TXT 读到文本不等于理解全部业务。
- 非标准表头、坏 JSON、未知结构、编码异常或缺列保留原材料及可读部分，解释未识别项；不得静默套演示字段。
- 每项可用信息保留来源性质、材料引用、行/字段位置，以及已知的时间、对象、单位、渠道、口径；未知就标未知。
- 原始材料、商家自述、提取、派生计算、公共参考与假设分开；空值不能使用 `Number(value) || 0` 转成零。
- 同一商品/时间/渠道不一致时显示冲突，不拼接漏斗；不把来源类型下拉选择当成已授权或已核实的证据。
- 旧会话仅有历史图片但没有业务描述时也可限范围继续，明确内容未识别、问题范围待核对；不得要求完整档案才能前进。
- 文件文本、文件名与用户输入按纯文本安全呈现；不执行附件内脚本或指令，不把它们作为开发授权。

## 共享衔接、错误、返回与刷新

所有有意义的输入变更都经共享操作推进 `inputVersion`，把问题置为待确认，并把依赖它的 analysis、selection、artifacts 标旧。
不能直接改底层存储绕开失效规则；不能因修改一项材料、刷新或返回第一页，就重置同一轮的补问预算。
同轮最多主动补问3项且一次1项；实际发问才占共享预算，回答/跳过后可在剩余额度内继续。保留全部问题/答案/来源，主动编辑和路径选择不冒充补问。
异步文件读取、预览与解析结束前核对输入版本/材料身份，忽略已删除或被替换任务的迟到结果。
保存状态只描述实际结果：本浏览器已保存、正在保存或保存失败；不称为 MoneyAI 记忆、云同步或多设备同步。
材料二进制能否刷新后恢复以共享存储能力为准；不得只存临时 object URL 却承诺永久预览。
保存失败时保留当前内存草稿、显示重试；不同真实页面依赖持久状态时先不跳转，不能以URL携带原始私密材料补救。
刷新或从第二页返回后，通过共享模块恢复真实已保存草稿、材料、确认版本与补问记录；不重新加载演示案例覆盖用户内容。
读回失败明确显示问题，不伪装成首次空白使用；旧版本/结构不兼容交由共享模块处理，不自行迁移或删除。
未知保留未知，缺材料仍可整理有限结果；空描述且无材料时提示先说一句或交一份，不能生成完整模拟诊断。
预览资源按实际生命周期释放；明确删除材料时删除原始Blob，保留历史元数据与执行记录，旧引用显示原件已移除；不能因历史引用而暗中保留或恢复已删除原件。
