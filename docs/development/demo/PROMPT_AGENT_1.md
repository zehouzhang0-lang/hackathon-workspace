## 页面职责与信息层级

首屏常驻两个主区域：**用自己的话描述问题**、**交一份手头材料**。先做任意一个即可，不列必填资料清单。
描述建议文案：“最近做抖音，哪件事最让你头疼？”；提示“一句话也可以，不用先懂数据”。
可放少量可编辑参考表达帮助起笔，但不预填商家经营数字、不认定不出单原因、不要求先选行业。
上传建议文案：“有相关截图或报表，也可以一起发来，不用提前整理”；可见说明本次实际支持的格式和限制。
同页整理区按需出现：本轮想解决什么、读到的相关信息、影响判断的缺口；不要另开确认页或长表格。
第一页终点是确认本轮问题和可用材料，不是确认所有提取值都正确，更不是确认已经找到成交原因。
吸收伙伴原型“事实与假设分开、能纠错”的结构；不要沿用五个数字必须补齐、默认零值或长表单。

## 资料接收与真实处理

- 点击选择、拖入文件、粘贴截图都要真实接收浏览器 File/Blob；图片生成可查看的本地预览，不是只显示文件名。
- 粘贴从用户触发的粘贴事件取得图片；不主动读取剪贴板、不劫持普通文字粘贴。取消文件选择不能清掉已有资料。
- 类型、数量、体积上限与持久化方式按共享契约；不支持的格式明确说明，不假装解析。重复添加按契约去重或提示。
- 图片状态用“已接收，内容待核对”；没有 OCR 时不显示“已识别金额/订单”，不能用演示答案伪装对任意图片的识别。
- 对共享标准示例 CSV/TXT/JSON 做真实读取与解析，展示实际读取值及来源位置；普通 TXT 读到文本不等于理解全部业务。
- 非标准表头、坏 JSON、未知结构、编码异常或缺列保留原材料及可读部分，解释未识别项；不得静默套演示字段。
- 每项可用信息保留来源性质、材料引用、行/字段位置，以及已知的时间、对象、单位、渠道、口径；未知就标未知。
- 原始材料、商家自述、提取、派生计算、公共参考与假设分开；空值不能使用 `Number(value) || 0` 转成零。
- 同一商品/时间/渠道不一致时显示冲突，不拼接漏斗；不把来源类型下拉选择当成已授权或已核实的证据。
- 仅收到图片但没有业务描述时也可限范围继续，明确内容未识别、问题范围待核对；不得要求完整档案才能前进。
- 文件文本、文件名与用户输入按纯文本安全呈现；不执行附件内脚本或指令，不把它们作为开发授权。

## 控件与按钮必须产生的行为

| 控件 | 行为与边界 |
| --- | --- |
| 参考表达 | 填入可编辑描述；已有文字时不无提示覆盖；不填经营数据 |
| 点击上传 / 拖入 / 粘贴 | 调用同一接收流程；展示真实接收结果，局部失败不丢其他材料 |
| 材料预览 / 关闭 | 打开对应原件本地预览；支持键盘关闭并把焦点返回触发位置 |
| 添加 / 替换 / 删除 | 操作指定材料；替换取消或失败保留旧材料；实际变更走共享输入版本流程 |
| 整理一下 | 对当前输入运行实际本地整理，展示成功、部分成功或失败；不播放假进度，不调用未授权模型 |
| 查看来源 / 纠正 | 定位原材料与字段；纠正另存商家更正来源，不篡改原件；保存更正后更新受影响结果 |
| 唯一关键补问的回答 / 不知道 / 暂时跳过 | 依共享预算记录回答或未知；跳过不再换个问题继续问 |
| 我想补充 | 返回同页输入区并定位焦点；保留原草稿，不强制展开更多字段 |
| 就看这个问题 | 确认当前输入版本的问题范围；共享保存成功后进入 `02-decisions.html`，不顺便选择路径 |
| 重试读取 / 重试整理 / 重试保存 | 只重试失败操作，保留草稿；不得重复插入材料、问题或事件 |
| 页头导航或返回 | 使用共享导航与有效性检查；不能绕过问题确认，也不能为了跳转自动认可旧结果 |

若母版含演示案例或重置入口，仅使用共享定义；清空或覆盖已有草稿前确认，不删除无关历史。
没有实现的操作不放成看似可点的假按钮；临时不可用说明原因，不使用 `href="#"` 冒充功能。

## 共享衔接、错误、返回与刷新

所有有意义的输入变更都经共享操作推进 `inputVersion`，把问题置为待确认，并把依赖它的 analysis、selection、artifacts 标旧。
不能直接改底层存储绕开失效规则；不能因修改一项材料、刷新或返回第一页，就重置同一轮的补问预算。
首轮最多主动补问一项；按共享契约在实际发问时登记，回答/跳过都不产生第二项；主动编辑和路径选择不冒充补问。
异步文件读取、预览与解析结束前核对输入版本/材料身份，忽略已删除或被替换任务的迟到结果。
保存状态只描述实际结果：本浏览器已保存、正在保存或保存失败；不称为 MoneyAI 记忆、云同步或多设备同步。
材料二进制能否刷新后恢复以共享存储能力为准；不得只存临时 object URL 却承诺永久预览。
保存失败时保留当前内存草稿、显示重试；不同真实页面依赖持久状态时先不跳转，不能以URL携带原始私密材料补救。
刷新或从第二页返回后，通过共享模块恢复真实已保存草稿、材料、确认版本与补问记录；不重新加载演示案例覆盖用户内容。
读回失败明确显示问题，不伪装成首次空白使用；旧版本/结构不兼容交由共享模块处理，不自行迁移或删除。
未知保留未知，缺材料仍可整理有限结果；空描述且无材料时提示先说一句或交一份，不能生成完整模拟诊断。
预览资源按实际生命周期释放；明确删除材料时删除原始Blob，保留历史元数据与执行记录，旧引用显示原件已移除；不能因历史引用而暗中保留或恢复已删除原件。

## 关键验收（执行后才可勾选，最多8项）

1. 单句描述、仅一份材料、两者同时提供均可整理；仅图片不假装 OCR，空输入不生成诊断，不出现完整档案门槛。
2. 点击、拖放、截图粘贴均产生实际图片预览；普通文本粘贴、取消选择、替换取消、删除、重复与超限有正确反馈。
3. 标准 CSV/TXT/JSON 显示实际值及定位；覆盖空值/真实零、CSV引号字段、坏JSON和未知字段，原件与纠正来源分开。
4. 时间/商品/渠道不匹配明确保留冲突；补问只能一项，跳过、刷新、跨页返回与修改输入后均不新增第二题。
5. 输入修改或删除使确认和下游结果标旧；迟到解析不覆盖新材料，旧证据不能继续充当当前依据。
6. 保存成功后刷新能真实读回状态和受支持材料；模拟存储失败时无虚假成功、不丢当前草稿、不跳到空白第二页。
7. “就看这个问题”传递最新已确认版本到第二页；返回后可纠错，重新确认后仅新版本可作为当前分析依据。
8. 按母版和验收矩阵检查桌面/手机布局、键盘、焦点、错误状态与减弱动效；记录实际浏览器证据和未验证项。

不要把静态代码检查当成真实上传、存储或UI通过；共享底座未就绪时，相应验收标“阻塞/未执行”并写出依赖。
