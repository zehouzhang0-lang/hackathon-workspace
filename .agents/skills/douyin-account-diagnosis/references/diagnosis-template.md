# 账号诊断检查项与报告模板

本参考用于需要完整诊断报告或行动实验时。它提供定性检查项和证据结构，不提供账号总分、固定行业阈值或平台准入门槛。

## 三、五维检查项

### 1. 账号健康信号

检查：

- 是否存在平台正式违规通知、功能限制或申诉结果，以及通知日期和适用对象。
- 发布、推荐或搜索是否发生变化；比较窗口和内容条件是否一致。
- 是否同时存在内容类型、发布频率、流量来源或账号设置变化等替代解释。

输出规则：

- 有平台正式记录：准确转述记录，不扩大范围或期限。
- 只有异常现象：写“出现待核查信号”，列出替代解释和创作者中心核验路径。
- 没有数据：写“未知”，不能写“健康正常”。

### 2. 定位与人设一致性

检查目标受众、核心需求、价值主张、头像昵称简介、内容主题和表达方式是否互相支持。对审美和辨识度只做有证据的观察，不用主观数字代替说明。

### 3. 内容质量与结构

针对用户提供的样本观察：

- 选题是否服务当前目标和受众。
- 开头是否清楚交代价值或情境。
- 信息、演示、证据和行动引导是否完整。
- 画面、声音、字幕、封面和标题是否影响理解。
- 不同内容类型是否能在口径一致的历史数据中比较。

不把单条内容表现外推为整个账号结论。

### 4. 数据表现

只分析用户实际提供且定义清楚的指标。记录分子、分母、单位、对象、统计窗口、自然或付费流量，以及人数或次数口径。比较方法见 [industry-benchmarks.md](industry-benchmarks.md)。

### 5. 变现路径匹配

检查：

- 用户想达成的经营目标及时间范围。
- 受众需求与商品或服务是否匹配。
- 内容到咨询、点击、下单、支付或履约之间的承接证据。
- 库存、客服、售后、资质和交付是否形成约束。
- 平台当前规则是否已通过官方来源核验。

不要凭粉丝数给出准入结论；没有当前规则依据时写“平台条件待核验”。

## 四、瓶颈候选选择

候选问题应同时说明：

- 影响：为什么它可能阻碍用户当前目标。
- 依据：引用哪些事实或可比数据。
- 不确定性：哪些替代解释仍成立。
- 可行动性：是否能用低成本、可回滚的动作验证。
- 风险：若判断错误，可能产生什么损失。

数据降幅最大不必然是最值得先验证的问题，也不构成根因证明。
