1. **旧理解 A／当前已更正 B。** 核对区同时显示两者。只有用户打开字段并明确核对 B，才以 B 为本次编辑起点，追加 B→C；保留原始转写、完整更正前缀、fact ID 及原 fact_correction。提交核对打开时的 fact/round/inputVersion 快照，后来再变就拒绝。数组对应或类型不明确时可读地保留冲突并阻止该项保存，不按索引猜值，也不把 B 自动灌入其他字段。

5. **示例／重置／返回。** 新 state 不含 intake 且本页无脏稿时，清理旧理解、绑定、编辑/来源上下文和旧步骤；connect 判空后再恢复。若有脏稿则保留原文及旧轮来源语境，不自动丢弃或重套新轮。补问返回核对后保留未提交文字；同题输入版本改变须再次明确核对，跨轮或另一题不能自动绑定。
