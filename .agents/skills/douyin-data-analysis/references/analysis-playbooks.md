# 分析方法

## 共通分析框架

按“目标 → 口径 → 描述 → 对比 → 解释假设 → 实验”推进：

1. 把业务问题翻译成一个主要指标和必要的保护指标；
2. 确认观察窗口、分母和可比组；
3. 先描述规模、分布、趋势和异常；
4. 再做同账号历史、分组或竞品对比；
5. 将可能原因写成假设，列支持证据和反证；
6. 只在证据足以支持验证时，把最高价值假设变成可执行实验；不为填满报告生成实验。

## 基础数据分析

### 播放量

依次检查：

- 累计播放和发布后固定窗口播放；
- 中位数、均值、分位数和离群点；
- 推荐、搜索、主页等来源结构；
- 按日期、内容类型、时长和发布时段分组；
- 异常变化是否伴随选题、形式、活动或流量来源改变。

只有播放量时，只能描述表现和提出补数方向。没有曝光或早期留存，不能确定是封面标题、内容开场还是分发问题。

### 互动率

先算总体率和典型视频中位数，再拆点赞、评论、分享、收藏：

- 点赞高不必然意味着讨论或传播强；
- 收藏和分享可能更适合知识或工具内容；
- 评论高要区分正向讨论、争议、咨询和售后；
- 互动高但转化低时，检查受众意图、价值承诺与下一步路径。

评论文本只有在用户提供或工具可访问时才分析；没有评论正文不能编造关键词。

### 完播与留存

先确认拥有的是实际完播率、平均观看时长，还是分段留存。按“起播 → 3 秒 → 15 秒 → 中段 → 结尾”定位最大绝对或相对流失区间。

可形成的假设示例：

- 3 秒流失大：选题承诺、首帧或开场表达需测试；
- 中段流失大：信息重复、节奏或结构可能有问题；
- 结尾流失大但核心内容已交付：CTA 过长或结尾价值不足。

这些都是待验证解释。结合视频内容或脚本证据后再提高置信度。

### 转化漏斗

按实际数据建立漏斗，不跳层。只有相邻层级属于同一对象和归因窗，且分子确实属于分母覆盖的人群或事件时才能计算转化率：

`曝光 → 播放 → 主页访问 → 关注`，或 `观看 → 商品曝光 → 点击 → 下单 → 支付`。

为每层显示人数、相邻转化率和绝对流失。若无法证明层级嵌套，则分列指标并标明不可拼漏斗。优先优化“规模足够且流失显著”的层级，而不是只挑百分比最低的一层。

### 端到端报告

整体报告按实际可用数据包含播放、互动、留存和与目标相关的转化；缺失项明确列为不可分析，不补造指标。TOP/BOTTOM 除播放量外还应在数据可用时对比内容标签、时长、留存和转化，避免把“高播放”自动等同于“高质量”。

## 粉丝画像分析

### 性别与年龄

展示各组占比、快照日期和与上期变化。将画像用于提出内容适配假设，不按性别或年龄套刻板偏好。粉丝结构变化可能来自近期爆款，应与新增粉丝来源和内容周期一起看。

### 地域

检查 TOP 地域、集中度和时间变化。地域差异可用于语言、案例、节日和发布时间测试，但不能仅凭省份推断收入、职业或消费能力。

### 活跃时段

区分“粉丝在线高峰”和“发布后表现最佳时段”。先用活跃分布提出 2–3 个候选窗口，再在相似内容上交叉测试；不要把一次高播放直接归因于发布时间。

### 兴趣标签

将标签分为核心兴趣、相邻兴趣和探索兴趣。观察排名或占比变化，结合内容表现形成选题实验。兴趣标签是平台或工具的分类结果，不是个体事实，也不应限制账号只能做单一主题。

## 内容分析

### 爆款共性

先用账号内部、固定观察窗口定义爆款，再给每条视频标注选题、形式、时长、首帧、开场、结构、CTA 和发布时间。寻找：

- 多个爆款都出现且普通视频较少出现的特征；
- 同样包含该特征但没有爆的视频，作为反例；
- 特征是否与账号阶段、活动或流量来源混杂。

输出“可复制假设”，不把共性写成保证爆款的公式。

### 低播放诊断

按数据漏斗排查：

1. 曝光不足：分发、账号阶段、内容主题或发布时间是候选假设；
2. 曝光足但进入低：封面、标题和受众匹配是候选假设；
3. 进入后早期流失：首帧、开场和承诺兑现是候选假设；
4. 留存尚可但互动低：信息价值、情绪或互动机制需测试；
5. 互动尚可但转化低：人群意图、账号定位、CTA 或商品路径需测试。

只拥有播放量时停在第 1 层描述，并列出下一步需要的曝光、留存和互动数据。

### 内容类型对比

每组显示样本量、固定窗口播放中位数、总体互动率、留存与转化。不同类型服务的目标可能不同，应按目标判断：剧情可能带播放，教程可能带收藏或转粉，商品内容可能以点击或下单为主。

组间样本过少或发布时间集中在不同阶段时，不宣布哪种类型“最好”。

### 发布时间

按星期和小时分组，控制内容类型、观察窗口和活动期。对每个时段显示样本量和分布。将粉丝活跃时段作为候选，不把相关性当因果；用交叉时段实验确认。

## 竞品分析

### 监控

固定账号列表、采集日期、来源和观察窗口。跟踪公开可见的粉丝变化、更新频率、固定窗口播放、互动分项、内容方向和爆款分布。不同第三方工具的数据不可直接混用，除非已校准。

### 差距

同时比较规模、效率、稳定性和内容结构：

- 规模：粉丝、总发布量；
- 效率：单条中位播放、互动或转粉；
- 稳定性：分布、爆款占比、更新连续性；
- 结构：选题、内容形式、时长和转化目标。

把差距分成可控、部分可控和不可控。粉丝绝对差通常不是下一步行动本身。

### 优势和 SWOT

每个 SWOT 条目附证据或标记待验证。优势来自己方相对表现、独特资源、专业能力或粉丝响应；机会和威胁涉及外部趋势时，需要当前来源，不能用通用套话填满四象限。

### 追赶策略

从有证据的可控差距中按需要选择短期实验，不设固定数量；没有足够依据时先补数。再规划中期资产：选题库、系列化内容、专业证据、人设或制作流程。不要照搬竞品的标志性表达、人物设定或具体作品；学习机制并形成差异化。

所有预期效果写成目标或验证门槛，不承诺“平均播放提升 30%”等无依据结果。
