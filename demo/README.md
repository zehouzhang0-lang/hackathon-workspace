# 路芽｜商业第二大脑 Demo

2026-08-29 按用户选中的 Demo 界面替换原前端。固定侧栏、浅灰绿工作区和深绿主操作已接回原项目业务；保留原生三页、路芽品牌、IndexedDB 状态和同源 Python API，没有另建 React 工程或导入独立 Demo 的模拟状态。

## 启动

在仓库根目录运行：

```powershell
python -B -X utf8 server/app.py --port 4188
```

打开 [本机工作台](http://127.0.0.1:4188/01-intake.html)。根路径也会跳转到第一页。前端无构建步骤和安装依赖；修改页面后刷新即可。

如果端口已由本项目使用，复用原服务，不清理未知进程。Windows 的 `python` 若指向 Microsoft Store 占位符，请改用已安装 Python 的完整路径。只使用 `127.0.0.1`，不要混用 localhost、不同端口或 file 协议。

## 演示走读

1. **经营资料**：填写本轮问题并上传资料，或点“选择示例资料”/“演示指南”载入榨汁杯合成案例。不会默认替用户载入数据；载入和清空均需明确确认。
2. **核对理解**：点击“开始整理”，查看六组摘要、来源和未知。先确认理解，必要时补问，再点击“确认，开始分析”。可以更正信息；原话、更正与来源保留。
3. **成交方案**：比较本轮实际返回的方案，查看风险、未知和完整依据；榨汁杯首轮 A 是详情页首屏，B 是真实问题验证内容。明确选择后才进入执行页，不默认选路。
4. **操作与成品**：查看选定方案的文案、核对清单和观察计划，切换内容/使用步骤，复制或请求下载执行包。取用内容不会记为采用或执行。
5. **反馈与复盘**：分别记录采用、实际执行、观察、样本与限制。空白保持未知。保存后重新读回关联稿件，再查看本机共享规则的复盘。
6. **下一轮与档案**：只有共享规则返回可接受候选且用户明确接受，才原子建立下一轮。侧栏“活动档案”保留每轮资料、选路、交付版本和反馈；“商业记忆”只读汇总原会话，不另建存储。

榨汁杯合成案例可演示“首屏已执行 + 新增商品点击达到原计划门槛 + 自述无明显变化”后提出购买问答区候选。该条件沿用原共享规则；不意味着统计充分、科学证伪或真实经营效果。其他资料、未执行、样本不足和未知反馈不会被强行套入这个闭环。

## 数据与能力边界

只读成品是当前基础范围，复杂编辑和历史稿导出未完成。CSV/JSON按白名单解析；首页已接线新图片与XLSX/XLS接收：单份10,000,000字节／6份／20MiB，PNG/JPEG/WebP可预览缩略图与来源类别标注。XLSX已由共享层在本机解析已知指标列（抖音作品导出、榜单快照、metric约定表）：中文单位换算、区间/下限估值按未知保留、「口径说明」表进入核对提示、整列全0按采集缺失处理；解析结果进入第一页「已读取数据」，确认后由共享本机分析承接第二页（五阶段漏斗／流量层／承接层／内容层，全部输出为待验证判断，不调用真实模型）。XLS旧格式仅接收，解析未支持；新旧图片没有OCR，内容均待核对，不宣称任意模型理解。OCR与P3反馈材料接线仍未完成。缺失不补0，口径冲突不拼漏斗，假设情景不等于成功概率或行动增量。可用合成[XLSX榜单样例](samples/README.md)验收。

- 当前分析与复盘为明确标注的本地规则。MoneyAI 接入已按产品决定移除；「AI 设置」（页面底部）可配置你自己的 OpenAI 兼容 API，配置后第一页「整理」会把描述与原文发送到你设置的地址进行结构化提取，未配置前不外发任何资料。
- PNG/JPEG/WebP 可接收与预览，未进行 OCR。XLSX 可保存原件，并由共享层在本机解析已知指标列（抖音作品导出、榜单快照、metric 约定表）；XLS 仅接收原件，解析未支持。CSV/JSON 仅解析约定结构，TXT 保留原文。详见[上传样例](samples/README.md)。
- 上传限制：单文件最多 10,000,000 字节、最多 6 份、总计 20 MiB。反馈页的新截图/表格附件尚未接线，可先保存文字、执行自述与数据。
- 语音由浏览器支持情况决定，使用前须确认处理方式；本次没有授权麦克风或验证在线识别。
- 已确认事实、商家假设、未知分别显示；商品点击到加购率按比例存储，表单以百分数填写。缺失不补零，不因更正或换方案恢复旧值。
- IndexedDB 只在当前浏览器和同源下保存，不随 Git 同步；换设备不会自动带走资料。历史稿保持原版本，复杂在线编辑未实现。
- 不自动发布抖音、不投流、不承诺成交；没有部署上线或提交、推送代码。
