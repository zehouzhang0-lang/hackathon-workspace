## 本页应当展示什么

- 顶部简要显示本轮问题、商家/商品范围、轮次、选定路径与版本；提供“回去换一条路径”。
- 主体首先展示该行动真正需要的可用内容；一条回复就给一条，不为凑模块额外生成标题、视频和报告。
- 每个成品附使用位置、事实依据摘要和必要风险；用户可直接复制或导出，不先回答反馈问题。
- 操作清单只包含当前路径必要步骤。实验计划复用第二页已给的指标、观察窗口、分母与限制，不在本页重新诊断。
- 样本下限、预计耗时和预算须附已有依据或“演示假设”；未知保持未知，不默认填100次点击、已跑满或已回滚。
- 面向顾客的成品不能混入商家内部约束，例如“老板没时间重拍”“暂时不能降价”。
- 深层来源、详细依据和历史版本按母版约定展开；关键使用风险不能藏在折叠区或下载文件里。
- 不重做第二页路径比较、大型决策树、置信区间计算或经营仪表盘；完整路径报告沿用第二页入口。

## 成品取用与编辑

复制成功必须来自实际剪贴板操作成功；失败保留文本并给手动选取方式，不显示“已复制”。
导出必须生成真实可读取文件，内容、编码、文件名和来源标签按共享契约；不能放假下载链接。
浏览器发起下载最多记录 `download_requested`，不能宣称文件已经落盘；导出不代表选择、采用或执行。
模板、规则拼装或预写参考稿必须持续标明“演示生成/参考稿”；不显示真实 MoneyAI 生成或长期记忆成功。
允许修改文字口吻并保留稿件版本；涉及规格、价格、承诺或行动范围的修改，须按共享失效机制重新核对。
缺少必要商品事实时展示待补信息或核对步骤，不能编造发货、运费、效果、尺寸或售后保证。

## 轻量反馈：随时可选，不拦取用

反馈入口为“记一下实际情况”，默认不展开整套表单；退出、不反馈或回第二页都不算拒绝或失败。
最小输入只有“动作是否实施”与一句实际观察，二者均允许未知；计数、执行日期和观察期只在用户主动展开时出现。
观察标签如“好一些/没变化/变差”必须由用户明确选择；不得仅靠关键词把一句模糊描述转换为成效结论。
不重新询问首轮行业、商品、流水或漏斗；已有来源与限制直接读取，同轮补问额度跨页共享，不重置。
用户可只记录部分实施、阻碍或新情况；保存执行时间未知的记录是合法路径，不为了保存强迫补日期。

## 状态必须分清，不把状态机摆成问卷

| 语义 | 本页约束 |
| --- | --- |
| 实际执行 | `unknown / not_started / partial / done`；默认 unknown，完成是商家自述，不是平台核验 |
| 结果观察 | `unknown / better / unchanged / worse`；独立于执行状态，未观察不填0或unchanged |
| 选择与采用 | 读取第二页显式选择；复制、下载不自动变成采用；无采用陈述时保持未知 |
| 时间与范围 | 分开实际执行时间、反馈时间和保存时间；未提供执行时间就留空，保留实际做了哪些部分 |
| 保存与读取 | 草稿、保存中、成功、失败、读回成功分别记录，不把本地保存说成云端或跨设备同步 |

点击“变差”不能写成“未采用”；部分实施后停止，仍保留已实施部分，不回写为从未执行。
一句“用了”不能自动标记所有片段已发布；范围不明时按自述保存，并保留未确认范围。
查看、选择、复制、下载请求、采用、执行、结果、保存和读回必须保持独立事件及版本关联。

## 保存、读回与下一轮

通过共享模块保存，不自行创建数据库；共享方案使用 IndexedDB 保存 JSON/Blob，页面等待事务完成后的成功确认。
成功后才显示“已保存到本机浏览器”，并注明对应行动/版本与实际保存时间；保存前是草稿。
禁用存储、容量不足或写入失败时保留当前草稿，说明尚未保存；允许重试，不重复生成同一条正式反馈。
刷新后必须真实读回对应记录，才显示“已读取本机记录”；读取失败不能用预载案例伪造历史。
提供显式“带着反馈再分析”入口，通过共享流程建立新 round，再跳回第二页；不能在本页预写“下一轮已改善”。
携带上轮事实、限制、选路、成品版本和真实执行/观察记录；按记录性质区分模拟、自述、已保存与实际读回。
共享创建流程须处理重复点击：一次确认只创建一个新 round，保留历史与事件，不把数字直接改成固定的2。
未保存草稿若要带入下一轮，须由共享契约明确支持并标为未持久化；否则提示先保存，不静默丢弃或伪称读回。
“没变化”只是一条观察，不能自动证明行动失败或强制换路；样本不足、时间不明或口径不同应带回第二页再判断。
出现恶化可以提示原计划已有的暂停/回滚条件，但不能自动记录已暂停、已回滚或已完成新行动。

## 必须处理的异常与版本变化

- 直接打开本页但没有显式选路：展示说明并引导第二页，不替用户默认选A，也不显示虚构成品。
- 输入或选路版本变化：旧成品标为历史只读/待更新，不继续作为当前有效建议；历史执行仍指向旧版本。
- 回第二页换路：保留旧执行和反馈；未保存编辑须提示真实去向，不因导航清空记录或变成拒绝。
- 旧版本若允许导出，仅作为明确标注的历史材料，不能继续提供无提示的“拿去执行”。
- 共享状态缺失、损坏或版本不兼容：使用契约定义的恢复入口，不私自迁移、清空或覆写别页状态。
