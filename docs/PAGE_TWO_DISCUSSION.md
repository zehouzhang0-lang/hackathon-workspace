# 第二页讨论稿：看懂判断，决定下一步

更新：2026-08-28。**本文件是待用户逐项回应的建议，不是已批准规格，也没有完成实现或测试。**

本次只整理交互与功能问题，不生成视觉、不写应用代码。明早可以优先回应第7节的 **P2-Q1—P2-Q4**；其余内容是为了说明每个选择会怎样影响使用。

**默认主张：先让老板看懂“目前知道什么、先做什么比较合适”，再决定本轮的一件事。多维判断按相关性展开，不做全店评分，不固定三个问题，也不为排版凑两个方案。**

## 1. 已确认的基础与本页建议的边界

### 来自第一页的已确认约定

依据：[第一页交互约定](PAGE_ONE_SPEC.md)。

- 商家用自己的话、手头材料或两者开始，不要求完整档案。
- 第一页整理本轮问题、可用依据和关键缺口，允许纠错及跳过。
- 点击“就看这个问题”，确认的是本轮关注范围与可用资料，不代表逐项核实提取值，更不代表原因已经成立。
- 原件、提取结果、商家自述、派生计算、公共参考和模拟假设保留各自性质；时间、对象、渠道不同的数据不能随意合并。
- **同一诊断轮次最多主动补问一项。第二页不能重新获得一份提问额度。** 第一页已问过或商家已跳过时，本页保留缺口、缩小判断范围或说明行动前置条件。商家主动补充和纠错不属于系统连续追问。

### 本页尚未确认

以下主流程、信息顺序、路线选择方式和跨页行为均是建议。旧版[MVP案例规格](MVP_SPEC.md)及其固定双选项不作为当前开发基线。

## 2. 建议的主流程

**承接本轮问题与资料 → 给出短判断及适用范围 → 说明一条优先动作和必要的替代路径 → 老板选择、暂不选择或纠错 → 把所选任务交给第三页。**

这里的“选择”只是确认接下来准备哪件事，不表示已经采用内容、已经发布或已经发生经营效果。

### 页面信息层级

| 层级 | 老板看到什么 | 如何控制信息量 |
| --- | --- | --- |
| 本轮范围 | “这次看的是……”及对应时间、对象；只有已知信息才展示 | 承接第一页，不再填一次表 |
| 核心判断 | 一句有边界的判断，例如“现有咨询提示，买家可能卡在是否适配；可以先验证这一点” | 不用“已经找到不出单根因”等表述 |
| 首选动作 | 做什么、为什么现在做、预计花多少时间或钱、有什么风险、准备观察什么 | 一条首选只是展示优先级，不替用户自动选择 |
| 其他相关判断与路径 | 其他可能影响本轮问题的维度，以及有实际取舍的替代行动 | 按需展开；可以没有替代方案，也可以不止一个 |
| 依据与未知 | 对应材料位置、判断中推断的部分、哪些信息仍缺失 | 影响选择的限制直接可见，来源细节按需查看 |

### “多维判断”具体是什么意思

围绕本轮问题分别看相关方面，例如内容表达、流量匹配、商品与报价、购买或咨询承接。它们是分析视角，不是固定栏目，也不是要求商家逐项作答的问卷。

每项判断说明三件事：**看到什么 → 目前能说明到哪一步 → 对本轮选择有什么影响。**

- 有材料支持的观察可以直接陈述，并能定位来源。
- 尚未证实的解释用“可能、值得先验证”等方式表达，并交代不足。
- 没有依据的维度保留“目前不能判断”，不贴“表现差”的标签；无关维度不必展示。
- 不生成健康分、原因概率、行业达标线或收入预测。不能从“未出单”反推某个原因必然成立。
- 说明依据不等于展示模型内部思考过程；呈现的是可核对的观察、限制与选择理由。

### 每条行动至少讲清的内容

| 内容 | 建议规则 |
| --- | --- |
| 具体任务 | 能描述成一次可执行的动作，不只说“优化运营” |
| 与判断的关系 | 它在改善哪个可见问题，或验证哪个尚不确定的解释 |
| 执行条件 | 需要什么权限、资料、工具或能力；未知不能当作已经具备 |
| 成本与限制 | 已知的商家时间、预算和不能做的事必须影响建议；估算需标明，不知道不能填0 |
| 风险与代价 | 可能增加的工作、覆盖不足、误导或其他实际风险，不只写“效果不保证” |
| 观察方式 | 后续看什么变化，以及什么情况需要暂停或调整；没有可靠阈值时不编数字 |

允许把“先核实一个关键事实”或“暂不改动，保留记录”作为合理动作。不能为了让流程继续而给明显违反商家限制的方案；前置条件未知时明确标注条件，不能宣称已经可执行。

## 3. 状态与主要操作

| 状态 | 本页应怎样表现 | 主要动作 |
| --- | --- | --- |
| 正在形成判断 | 显示真实处理状态，保留本轮问题与材料入口 | 等待；必要时返回修改。失败时保留输入并允许重试 |
| 有可用判断和行动 | 展示短判断、首选动作、关键限制及其他路径 | “就做这件事”，进入第三页准备对应材料 |
| 只有局部依据 | 明确哪些能判断、哪些不能判断；只保留不依赖缺口的动作或带条件的路径 | 选择适用动作，或主动补充；不重启一串问卷 |
| 暂无可靠行动 | 说明目前卡在哪个关键缺口，不输出装饰性的诊断 | 主动回第一页补充，或暂不继续；不强制编出方案 |
| 用户认为不合适 | 保留当前结果，让用户表达原因或直接暂不选 | 调整建议、纠错，或结束本轮选择 |
| 输入已变化 | 受影响的旧判断和路线标为待更新，不能继续当作当前依据 | 根据更新资料重新判断；仅浏览旧版不等于采纳旧版 |
| 服务失败 | 明确失败，不把预编写答案偷偷替换成真实分析 | 重试或返回；保留草稿的具体技术方式待实现确认 |

### 选择、不选、纠错与返回

- **选择：**明确选择一条行动后交给第三页。推荐项不预先勾选，不以用户看过页面代替确认。
- **暂不选择：**始终保留“这些暂时不合适”。可以选“时间不够、条件不具备、方向不对、暂时不做”等简短原因，也可自由写或跳过；原因不设为必填。
- **根据原因调整：**用户说“今天只能花5分钟”，更新的是本次时间；说“不想改商品页”，不能自动记成永远没有编辑能力。调整后仍由用户选择，不自动换路线。
- **纠错：**建议从依据旁进入“这条不对／我想补充”，回到第一页对应内容。保留当前问题与原材料；新增材料与更正建立清楚关联，不静默抹掉冲突。
- **返回第一页：**保留描述和材料，避免重新填写。真正修改了相关依据时，第二页旧结果及第三页依赖它的草稿应标为待更新，而不是自动删除全部历史。
- **从第三页返回换路线：**旧路线和已生成材料保留为旧版本，新选择决定后续准备什么。不能把先前的复制或选择记录改写为执行记录。
- **换问题或换经营主体：**回第一页确认新的关注范围，避免把别家店或别个问题的判断沿用过来。

## 4. 跨页交接建议

下表是信息语义，不是已经确定的接口、数据库结构或要求老板填写的新表单。

| 方向 | 需要保留什么 |
| --- | --- |
| 第一页 → 第二页 | 本轮问题与版本、材料及来源位置、相关提取信息、已知口径、冲突与缺口、用户的纠正、已提供的经营限制、本轮补问是否已使用或被跳过 |
| 第二页内部 | 每项观察与推断的区别、所用依据、判断适用范围、可选行动与前置条件、成本估计的性质、用户选择或暂不选择的记录 |
| 第二页 → 第三页 | 所选具体任务、选择所依据的资料版本、需要准备的材料类型、事实与不能编造的部分、已知执行限制、风险与观察目标；不携带“已经执行”的默认状态 |
| 输入更正后 | 哪些判断、路线和草稿受影响；旧版本可以查阅，但不能作为当前已确认的执行依据 |

建议与第三页讨论稿保持一致：第三页保存实际执行及新反馈后，通过“结合这次反馈看下一步”回到第二页，开始**新一轮**判断，不增加第四页。新一轮区分上次事实、当时的临时条件、实际执行和本次新增观察，不把过去的“今天没时间”自动当作现在仍成立。

**这一跨轮路径也是待确认建议。** 保存或历史读取未验证时，不宣称已具备长期记忆；读不到历史时要显示限制，不能伪造“我记得你上次……”的内容。MoneyAI、平台API、数据存储方式均不在本文件中承诺。

## 5. 具体走读：只用于检验交互的模拟案例

素材来自[历史模拟用例](../fixtures/underbed-storage.demo.json)。**商家、商品、数字、咨询和参考判断均为虚构；不是商家成效证据，也不限制本页只服务收纳商品。** 首轮只使用S1—S5，不提前读取第二轮反馈或预编写答案作为证据。

### 第一步：承接第一页已经整理的本轮范围

商家想知道：“最近一周做了抖音，商品有人看但没下单，我先改什么？”

可用材料：单只含盖外尺寸60×40×16cm、无脚轮、不可折叠；2只装69.90元；提供的标题及详情开头；5条选取的咨询；单商品7天访客186人、支付订单0笔、发布3条视频。商家本次可用20分钟，能改文字和回复咨询，不降价、不新增投流、不重拍。

这些指标没有渠道拆分，咨询不是全量样本，未读取完整商品页及自动属性栏。因此不能拼出“这3条视频带来186人”的转化漏斗，也不能从0订单确定原因。

### 第二步：短判断与相关维度

主判断参考：

> 目前更值得先验证的是：买家能否判断这款箱子适不适合自己的床底。你提供的开头没有测量提醒，几条咨询也在问高度、内外尺寸和横梁；但我们还没看过完整商品页，不能说这是不出单的主因。

展开后可看到：

- **商品表达：**有对应文字与咨询依据，可以检查适配说明是否够清楚。
- **报价与购买条件：**已知价格及件数，有咨询问运费，但没有运费资料；不能判断价格太贵，也不能生成包邮承诺。
- **流量匹配：**缺少渠道和可关联的数据，暂不能判断来的人是否合适。

这里恰好展示三个相关方面，是本例材料的结果，不是固定“三大问题”。

### 第三步：给出有实际取舍的行动

**首选：先补商品说明。** 用已知外尺寸和测量提醒修改提供的商品文字，准备购买指引。模拟估计约10分钟、无需新增现金支出；优点是一次修改可服务后续访客，风险是文字仍可能被跳过，且不能据此保证成交。

**替代：先用已有咨询验证。** 暂不改商品页，准备测量提问与回复，记录买家具体缺什么信息。模拟估计约15分钟、无需新增现金支出；获得更直接的线索，但增加人工回复，只代表咨询者。

本例两条行动均符合已知限制，所以可以比较。实际材料不足或只有一条可靠路线时，不要求保留两个选项。

### 第四步：选择或纠错

老板选择“先补商品说明”，第三页再准备对应文字与使用指引；这里不显示“已经发布”。老板也可以不选，并补充“完整页面其实有测量图”。此时回第一页补上相关材料，再更新判断，不能仍把“整张商品页没说明”当作事实。

## 6. 可观察验收点——均未执行

1. **不重复问卷：**同一轮第一页已使用补问、用户选择跳过后，进入第二页不会重新追问一串指标、预算或权限；缺口仍可见。
2. **判断能对上依据：**可从观察定位对应原始材料；商家自述、推断与事实来源不混用；186人及0笔订单不会被展示成已证明的短视频因果链。
3. **数量随材料变化：**分别输入无可靠依据、仅支持一个行动、支持多个取舍的材料时，页面不会硬凑三个问题、两条路线或全维度评分。
4. **限制真正影响行动：**给出不投流、不降价、不能拍摄等已知条件后，不出现违反条件的推荐；未提供预算不显示“零成本”；时间估计有性质说明。
5. **选择可以撤回：**可以选择、暂不选择、跳过不选原因、返回补充和改选；进入第三页不被记为执行成功，草稿不会因返回而消失。
6. **更正使旧结果失效：**更正尺寸、统计期间或资料范围后，受影响的判断与路线标为待更新，第三页不继续使用旧参数；新轮次只使用实际可读到的历史，失败时显示限制。

## 7. 明早需要回应的四项决定

### P2-Q1：先给可行动的判断，还是先展示完整的多维诊断？

**默认建议：**先展示短判断、一条首选动作及关键风险，其他维度和替代路线按需展开。

理由：让老板先知道这轮能做什么，同时仍能追查依据。取舍是全貌不在第一屏；若选择“先看多维诊断，再选问题”，需要增加一次问题选择，页面也会更接近诊断工作台。

### P2-Q2：本轮只选一件事，还是允许同时选多件？

**默认建议：**一次选一件有明确目标的任务；一个任务可包含必要配套材料，例如商品说明与同口径回复，但不默认打包多个独立经营动作。

理由：便于执行和后续知道到底做过什么。取舍是暂不支持批量运营计划；多选则需要处理动作之间的冲突、执行进度和结果归属，不能只多放几个复选框。

### P2-Q3：还不能建议经营改动时，是否允许把“核实或观察”作为第三页的任务？

**默认建议：**允许选择一个有明确目的的小核实或观察任务，例如核对一项商品信息、记录几次咨询中的具体疑问，再去第三页拿对应的提示或记录方式。这不等于系统增加一串必答问题；同轮补问上限仍然有效。连核实目标都不清楚时，停在本页说明限制。

理由：在证据不足时，下一步仍可能是有用的验证，而非直接改经营。取舍是第三页需要支持文案之外的轻量交付；若只允许明确的经营改法进入第三页，其交付类型更少，但这类用户只能先补资料或暂不继续。

### P2-Q4：发现依据不对时，在第二页直接改，还是回第一页改？

**默认建议：**在第二页提供明确纠错入口，回到第一页对应位置修改，再更新第二页结果。

理由：避免两页分别维护一份资料，容易说明什么改变了。取舍是多一次页面跳转；若第二页允许直接修改，需要同步处理原件、提取项、冲突、版本与下游草稿，不能只改一行展示文字。

可以按编号回复“按建议”，只展开你不同意的部分；这些默认建议在你确认前不会被当作已批准的实现要求。
