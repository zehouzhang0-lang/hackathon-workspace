# 封面与画面方向

用于封面、构图、色彩、字幕和调色的文字设计说明；不生成或编辑图片、封面和视频。

## 先确认

- 视频主题、受众和希望传达的单一重点；
- 已批准的品牌、IP、字体、色彩、Logo 和禁用规则；
- 可使用的人物、产品、场景和素材许可；
- 目标平台及当前画幅、安全区和文字规范。

已有品牌规范优先。没有规范时，将视觉方向写成候选提案，不把建议当作已批准设计。

## 封面说明模板

- **信息重点**：用户一眼需要理解什么；
- **主体**：人物、产品、过程或结果中的哪一个；
- **标题候选**：简洁、准确并与内容一致；
- **构图**：主体位置、留白、字幕区和界面遮挡风险；
- **色彩与字体**：沿用品牌或说明提案依据；
- **素材状态**：自有、已授权、待授权或待替换；
- **待核验项**：规格、声明、对比图或商用许可。

标题可采用问题、对象加收益点、步骤摘要或场景描述，但不得夸大结果、制造虚假稀缺、贬低受众或隐瞒重要条件。数字、排名、效果和前后对比都必须有可追溯依据。

## 版式方向

- 真人内容：清楚表情或动作、简短标题、足够对比度；不要求夸张表情。
- 产品或教程：产品/成品、关键步骤或真实可比的前后状态；不得伪造效果。
- 知识内容：主题、对象和核心问题优先，减少与内容无关的装饰。
- 剧情内容：展示真实冲突或悬念，不提前承诺脚本没有兑现的信息。

提供多方案时，说明每个方案只改变的变量，例如标题表达、主体选择或色彩层级，便于后续比较。

## 画面与调色

调色应保持主体、肤色和产品外观可辨识。美颜、滤镜、锐化和对比度不能造成对产品效果、人物状态或场景条件的误导。字幕需考虑字号、对比度、显示时间和无声观看；必要时提供声音信息的文字替代。

若使用生成式画面、数字人或合成对比图，标明合成状态，并核对当前平台标识规则、人物授权、商标及素材许可。

平台尺寸与安全区可能变化；涉及当前规格时查询官方来源并记录核验日期，无法核验则标为待确认。
