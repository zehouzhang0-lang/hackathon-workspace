## 工作约定

文档链接与素材一致性检查（Python标准库，无需安装依赖）：

    python scripts/verify_demo_content.py

该脚本不运行界面或MoneyAI；验收用例仍需在真实实现中检查。

- 独立设备开工先检查工作区再同步；同目录并行时由统筹统一拉取、更新进度、提交和推送，页面Agent不操作Git写入，避免覆盖未提交工作。
- 重要决定和后续任务写入 `PROGRESS.md`，避免只保留在聊天里。
- API 密钥、令牌、密码和真实的 `.env` 文件不进入仓库；需要时只提交不含秘密的配置示例。
- 本轮使用原生HTML/CSS/ES modules与Python标准库，不需安装前端框架；先PC集成，手机专门设计后置。
