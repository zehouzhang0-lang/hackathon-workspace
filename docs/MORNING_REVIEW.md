## 跨页必须保留的约束

- **始终围绕本轮问题。** 第一页“就看这个问题”确认分析范围，不等于确认全部提取值真实，更不等于认可某个原因。
- **同一轮不反复补问。** 首轮最多主动补问一项，不按页面重置，也不把多个问题塞进一句话。用户主动补充或修改与系统追问分开处理。
- **资料的性质不升级。** 自述、原件、提取、派生计算、公共参考、假设分别保留；未知不等于零，对象和时间不一致的数据不拼接计算。
- **证据不足也有完整的去路。** 可以形成有限判断、待验证方向或暂不判断，不为了填满页面强凑原因、评分、固定数量的选项。
- **建议能被拒绝。** 每个行动说明适用条件、预计成本、风险和观察方式；未知能力不当作已具备。拒绝不触发一串必填问题。
- **取用不等于执行。** 选择、生成、复制、采用、实际执行和效果观察分开。没有执行反馈时保持未知，不能断言未执行；只做一部分不能称整套完成。
- **修改使依赖结果更新。** 改问题、纠错、删除材料后，相关判断和稿件需更新或标为失效；切换商家、商品或范围不能带入错误历史。
- **历史必须来自实际保存。** 保存失败保留草稿，不声称已存；读取失败不编造历史。模拟分支、本机存储、真实模型和 MoneyAI 能力分别说明。

## 跨页验收建议

以下均为**待执行**场景，不是功能通过记录。实际输入格式、解析服务、模型和存储方式仍待确认。

| 编号 | 输入与操作 | 必须观察到的行为 |
| --- | --- | --- |
| E2E-01 | 只写“有人问价，但没买”；唯一补问选择不知道 | 可以继续有限整理，不补出经营数字、不反复追问、不强制建完整档案 |
| E2E-02 | 只有一份受支持材料；本轮问题与资料的统计范围不一致 | 明确指出范围差异；允许修改本轮范围或保留限制，不直接计算不匹配的转化率 |
| E2E-03 | 产生候选后纠正资料、缩短可用时间，再表示都不合适 | 旧结果失效或更新；新建议尊重限制；不强迫选择、不自动进入产物页、不丢原资料 |
| E2E-04 | 选择路线并复制材料；随后只报告改了标题 | 复制不增加实际执行记录；没有反馈时执行未知；只引用商家报告的标题改动，不宣称其他内容已改或效果已验证 |
| E2E-05 | 反馈保存超时，重试后又出现历史读取失败 | 草稿保留、失败可见、重试不重复记同一事件；不能拿预写答案伪装读取成功 |
| E2E-06 | 相同新增资料分别对应已执行／明确未执行历史，并加入未预写规格变体 | 检查实际读取与所用依据；正确区分执行状态，不把未执行判为失败，不重复已完成工作；规格变化后不沿用固定答案 |

这些场景既要检查页面状态，也要在接入后检查真实请求与保存记录。旧的[15项模拟案例验收](DEMO_ACCEPTANCE.md)可以提供回归素材，但不能替代新交互的验证。
