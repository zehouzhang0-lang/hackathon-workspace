## 3. 页面职责与主要流程

承接第一页已确认的问题及资料 → 初步分析 → 比较路径 → 联动结果/证据/风险/业务树 → 可选下载 → 明确选择后进入 `03-action.html`。
顶部保留问题、经营对象、时间范围、输入版本及分析来源；未知信息写未知，不要求商家重新填一份表。
商家点开路径是“查看”，点击下载是“取阅”；只有明确的选路按钮才能产生选择事件并进入第三页。
路径必须按共享 `paths` 数组渲染：支持 0 条、1 条、多条。示例可以有两条，但不能固定 A/B、凑数量或无条件诊断出问题。
没有可靠判断时展示有限观察与缺口；可提供有依据的小核实任务，没有合适行动则允许暂不继续，不自动挑选一条。
允许“暂不选”与“返回补充”；拒绝原因不必填。本页不重新获得补问额度，同轮最多3问且一次1问，额度跨页共享；只在有剩余额度且当前无asked问题时继续，允许跳过和未知。

## 4. 路径、证据与风险的可视化

- 路径比较应看清动作、适用条件、时间/资金投入、观察目标与主要代价；未知成本不能写成零成本。
- 聚焦一条路径时，同步突出对应判断、支持证据、反面线索、假设、结果范围和业务树；不得出现标题切了但依据仍属上一路径的错配。
- 提供可追溯的“材料 → 观察/计算 → 有边界的判断 → 路径依据”，区分原件、自述、提取、推断、公共参考和合成假设。
- 证据缺失写“未提供/不可核对”；不能把前三条咨询称为高频，也不能把用户输入自动称为已验证事实。
- 关键风险、执行条件、停止与回滚提示在选择之前可见，不藏在下载文件、悬停提示或仅靠颜色表达。
- 风险预算或时间上限需说明来源；不是保证的最大损失。优先级不是成功概率，推荐不是替用户决策。
- 从证据旁纠错，按共享导航返回 `01-intake.html` 的对应来源/字段位置；保留草稿，不在本页维护第二份事实。
- 原 V0.4 仅参考实验的观察、停止、回滚结构；不复制其固定漏斗阈值、扣分置信度、固定 A/B 或关键词记忆逻辑。

## 5. 结果范围与真实性

1. 必须显式区分统计区间、假设下情景范围、暂不可估；“资料完整程度”和“模型自报信心”不能充当成功概率。
2. 首版使用共享底座提供、明确标注的合成情景及可复核算式；不擅自给真实商家填造数据或将演示输出伪装为实时模型分析。
3. 情景说明目标指标、观察期、每个假设、单位、计算与未覆盖的不确定性；上下界不是“95%置信区间”，也不是最大损失保证。
4. 只有共享结果确实包含合法方法、数据、置信水平及适用前提时才呈现统计区间；当前未提供则不能自行创造统计能力。
5. 基线可能结果与行动增量分开，不能将情景之间的差额直接写成“采用后多赚/多卖”；缺少识别依据时增量保持不可估。
6. 缺资料、口径冲突、分母为零、样本不足须正确降级；未知不等于 0，不拼接不同对象/时间/渠道的漏斗。
7. 处理状态只反映真实操作；预编写演示数据标为演示，不做伪模型思考动画。失败不得悄悄替换成成功的模板答案。

## 6. 决策树必须表达业务分支

树表达“执行后观察到什么 → 满足什么条件 → 继续、核实、调整或停止什么”，不是第一页到第三页的导航流程。
使用所选路径的共享树数据；分支条件、关联依据和下一步需读得懂，不能只有 Yes/No、成功/失败或装饰性连线。
区分观察不足、出现正向变化、没有明显变化、出现负面影响；没有经过验证的阈值不能填入固定样本数或时间承诺。
正向变化可以触发继续观察，不代表已证明建议有效；变化不明不能直接判失败，恶化分支应指向具体停止/回滚条件。
节点支持键盘操作和清楚焦点；窄屏提供顺序可读的分支列表，不能只能通过拖拽巨大画布理解或操作。
完整树进入报告，即使页面部分折叠也不能漏分支；数据损坏、无有效根节点或不支持的结构应明确失败，不假装完整展示。

## 7. 真实、安全的单路径报告下载

- 首版由客户端真实生成独立 `.html` 文件，可离线打开、可用浏览器打印；按钮明确标注格式，不承诺生成 PDF、云端链接或后端服务。
- 从当前路径及相应分析快照生成，内容含问题/对象/时间、输入与分析版本、路径标识、生成时间、演示或真实来源声明。
- 包含具体动作、支持/反面证据、可核对来源位置、假设与算式、结果类型及限制、成本、风险、观察/停止/回滚条件和完整业务树。
- 默认只导出允许共享的必要摘要，不嵌入未经同意的原始附件、个人流水、密钥、私密本机路径或临时访问令牌。
- 所有动态文字必须安全转义或以文本节点构建；导出文件不含脚本、事件处理属性、可执行用户 HTML、外部追踪或远程资源依赖。
- 使用固定安全样式和适合打印的排版；页面图示之外提供树的文字结构，报告离线打开后不能依赖应用脚本才能看全内容。
- 触发前验证当前版本并冻结对应快照；文件名使用安全字符及版本。及时释放临时对象 URL，不生成伪 `#download` 链接。
- 下载被阻止或生成失败时保留页面，给出真实错误与重试；不要以固定成功提示覆盖异常。
- 只记录共享契约的 `download_requested`。浏览器触发不证明文件已保存到磁盘，不记录或宣称 `download_completed`，也不产生选择、采用或执行事件。

## 8. 共享状态、过期与返回

只通过共享 API 读写和订阅；选路/导出前重新核对当前 `inputVersion`，处理其他页面或标签页产生的更新，不仅依赖本页缓存。
输入变更或分析不对应当前版本时，显著标记旧版；不得选择旧路径或将旧报告导出为当前。引导更新或回第一页，不能偷偷改写版本号。
未确认输入、无可读会话、共享存储失败等分别显示原因和恢复入口；直接打开第二页不自动载入一个假商家案例。
明确选择并成功写入共享状态后才进入第三页；写入失败停留本页，不用跳转掩盖。记录选择时执行状态保持未知。
第三页返回改选时保留旧选择和材料的历史关系；新路径只产生新选择，不继承或伪造旧路径的执行/反馈。
读取范围、生成结果、导出快照与所选路径都要版本一致；本页不实现长期记忆、真实商家接口、自动发布、投流或新付费调用。
