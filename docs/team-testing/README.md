## 2. 获取项目与安全更新

### 首次取得私有仓库

先用你自己的 GitHub 账号确认获准访问[私有仓库](https://github.com/zehouzhang0-lang/hackathon-workspace)。仓库不可见、403 或 “Repository not found” 时，找张泽厚核对成员权限；不要索要、粘贴或打印任何人的密钥／令牌，不把凭据写进 clone URL。

在你选定的父目录运行；目标目录已存在时停止，改走已有副本路线，不覆盖文件：

```powershell
git clone --branch master https://github.com/zehouzhang0-lang/hackathon-workspace.git hackathon-workspace
cd hackathon-workspace
git status
git branch --show-current
git rev-parse HEAD
```

这是在队友自己的电脑取得一份副本，不是在统筹共享工作区再克隆一份。GitHub 登录按你自己的正常凭据管理方式完成；本指南不要求读取本机凭据文件。

### 已有工作副本

先进入**已有仓库根目录**，不要重复克隆。逐条检查：

```powershell
git status
git branch --show-current
git rev-parse HEAD
```

只有工作区干净、处于 `master`、没有 merge／rebase 等未完成操作，且已确认 `origin` 指向上述仓库，才继续。若有未提交修改、未跟踪的重要文件、其他分支或独立提交，保留现场并找统筹确认；不自动 stash，不切分支，不以清空文件解决。

```powershell
git fetch origin
git status --short --branch
git log --oneline --left-right HEAD...origin/master
```

确认仍干净，且没有标 `<` 的本地独有提交：只有 `>` 表示远端新增；没有输出表示相同。此时才执行：

```powershell
git merge --ff-only origin/master
git status --short --branch
git rev-parse HEAD
```

任一步报错、出现分叉或拒绝快进，停止并反馈，不强行修复。**不使用无确认的 `reset --hard`、`clean`、强推或覆盖本地文件。** 同目录多人协作仍遵守 AGENTS 的唯一写入归属；页面 Agent 不自行同步 Git。测试不授权暂存、提交或推送。

## 3. 在自己的电脑启动

当前工程是原生 HTML／CSS／ES modules，加 Python 标准库后端。**没有 npm 构建步骤，也不需要为此安装前端框架或 pip 包。**

编写时实际核对：Windows PowerShell、**Python 3.13.9、Node v24.14.0**。Git 可用；Node 只用于自动检查，不是启动必需。其他 Python／Node 版本、macOS／Linux 和具体浏览器版本未复验，反馈时写实际环境，不当作已兼容。

```powershell
python --version
node --version
python -B -X utf8 server/app.py --port 4188
```

没有 Node 时跳过该版本命令，仍可试启动。命令应留在前台并打印：

```text
Local Demo: http://127.0.0.1:4188/01-intake.html
```

只在**自己启动它的终端**按 Ctrl+C 停止。macOS／Linux 若 Python 命令名为 `python3`，可以替换命令名，但应登记为未验证平台。

三页入口：[P1 资料确认](http://127.0.0.1:4188/01-intake.html) · [P2 找到优先问题](http://127.0.0.1:4188/02-decisions.html) · [P3 执行并记录](http://127.0.0.1:4188/03-action.html)。正常从 P1 顺序进入，直达 P2/P3 不应绕过确认／选择门槛。

- 全程用同一 `http://127.0.0.1:4188`，不双击 HTML，不换成 localhost、不同端口或 file 协议。后端还有 Host／Origin 校验；混用地址不只是存储隔离问题。
- 服务只绑定本机回环地址，提供 `demo/` 与限定 API；入口**没有** `/demo/` 前缀。不要改为公开监听、部署或用普通静态服务器替代项目后端。
- **不传 `--moneyai-url`** 即可使用本机演示，不需个人 MoneyAI、MCP、浏览器登录或信任配置。未配置／业务未接通是应披露的状态；真实提取不可用时应保留原文并允许人工核对。
- 端口已占用时不杀未知进程。确认是你已启动的同一服务后可复用；否则请统筹协助，或在确认空闲后另选端口，并把全部页面地址和反馈中的来源一并改为该端口。

真实入口与边界见[应用说明](../../demo/README.md)、[后端入口](../../server/app.py)。统筹机器的 4188 已有服务；在该共享目录工作的 Agent 不重复启动。
