## 工作约定

- 每次开工先拉取最新内容，结束时更新进度、提交并推送。
- 重要决定和后续任务写入 `PROGRESS.md`，避免只保留在聊天里。
- API 密钥、令牌、密码和真实的 `.env` 文件不进入仓库；需要时只提交不含秘密的配置示例。
- 技术方案确定后，再补充代码目录、安装步骤和运行说明。
