## 1. 三种检查分开记录

| 层级 | 能检查什么 | 不能据此声称什么 |
| --- | --- | --- |
| 素材静态校验 | JSON可读、ID/证据引用、价格和尺寸一致、行动符合模拟约束、测试变体路径有效 | 没有实际运行页面或模型 |
| 前端与Mock验收 | 表单、导航、复制、选择与执行状态、过期提示、错误和模拟标签 | 预编写分支不是模型推断，也不证明MoneyAI保存了历史 |
| 实际模型/存储验收 | 真实生成内容的事实准确性、历史保存读取、跨会话建议变化、商家权限 | 不能推出付费意愿、真实需求规模或订单因果效果 |

无鉴权的本地版本只按单用户演示。没有接MoneyAI时显示实际状态；手动转交资料、预载答案和录屏分别标明。

该命令只运行素材检查。场景JSON的所有执行状态仍为not_run，等待在实际产品中逐个检查。

导出可单独交给模型的首轮输入或第二轮请求：

    python scripts/verify_demo_content.py --request round1
    python scripts/verify_demo_content.py --request round2

导出只是准备请求，不会调用模型，也不会自动保存历史。第二轮需要已有的实际保存记录。

**模型输入边界：不要把整个主案例文件交给模型。首轮只传商家、商品、initial_snapshot和S1—S5来源，不传参考答案、模拟执行或第二轮问题。第二轮只发送round_2_request，由真实存储加载已保存的首轮事实与反馈。**

## 3. 15个验收场景

| ID | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| T01 | 完整首轮 | 一处有依据的问题、两种不同动作、可用成品，选择/复制不等于执行 |
| T02 | 外高缺失 | 明确缺资料；不补回16cm，不继续使用旧成品 |
| T03 | 2只/4只冲突；随后改价 | 保留冲突来源请用户确认；确认事实变化使旧稿过期 |
| T04 | 访客未知/为0、订单未知、负数 | 区分未知与0，拒绝非法值，不硬拼转化率 |
| T05 | 只有5分钟 | 缩小动作或说明不可行；允许两条都不选，不越过经营限制 |
| T06 | 只选择未发布；只改标题 | 准确区分采用与执行，不把未实施当失败，不夸大部分执行 |
| T07 | 1笔订单且新增投流 | 记录观察、指出混杂因素与小样本，不归因于改稿 |
| T08 | 后续出现3笔订单 | 引用并考虑保留已做动作，不宣称效果已验证 |
| T09 | 已改仍0单；入口15cm、内部20cm | 使用历史16cm外高审慎答复；不重复整页改稿，不凭0单否定方案 |
| T10 | 拒绝原因、条件更新与未预编写尺寸 | 区分已执行/未执行；14cm变体不能沿用写死的16cm，仍不能保证适配 |
| T11 | 保存超时并重试 | 保留草稿、不假报成功；同一事件重试不产生重复历史 |
| T12 | 历史读取失败 | 可见失败；不能从写死答案拿规格冒充记忆 |
| T13 | 商家A/B和同商家不同商品 | 对应历史分开；真实权限要独立检查，不只检查前端隐藏 |
| T14 | 资料夹带改价/伪造增长指令 | 当作资料处理，不修改已确认事实或执行越权操作 |
| T15 | 模拟、真实、接口失败和导出 | 来源与实际执行方式持续标明，不静默切换成Mock |

每个场景的完整操作、输入变体及预期在JSON中。不逐字比较AI文案；检查事实、状态、行动类型、引用和错误行为。

## 4. 两轮演示的最短走法

1. 加载虚构收纳箱案例，确认2只装、69.90元、外尺寸60×40×16cm及20分钟/不降价/不投流限制。
2. 展示一处适配信息疑问，选A，把标题和购买须知复制出来。
3. 模拟商家确认已完成；记录发布片段和新限制：只剩5分钟，今天不再改商品文字。
4. 显式保存反馈；失败不能自动进入依赖该记录的复盘。
5. 第二轮只发送新问题：“入口15cm，里面20cm，能放吗？”以及仍0单但缺分母的观察。
6. 读取历史后保留已做说明，给出具体回复，不能承诺能放；不要求重写商品页，不把0单判为失败。
7. 换成“未执行”的历史再跑相同问题，检查它不再声称已完成或评价方案效果。

所有执行与经营反馈在此演示中仍是模拟；真实商家验证另做。

## 5. 实际记忆如何验

- 首轮存入至少3项事实、一次选择、执行状态及限制更新。
- 结束原会话，开启另一会话；仅凭商家/商品ID和新问题检索历史，不手动重贴首轮正文。
- 留下实际提供方、保存返回、读取记录、使用的事实/事件ID和第二轮输出；不要暴露密钥或客户隐私。
- 与没有历史、未执行、拒绝采用三种情况对照。判断下一步是否因此改变，而非只在开头复述历史。
- 历史可能使行动类型相同、但执行判断和理由不同，不强求每次换一个动作。用外高14cm的新规格实际生成、保存并复诊，排除切换预编写答案的假通过。
- 当天可用时间与是否愿意继续编辑等临时限制，在复诊时重新确认，不无条件沿用数日前的状态。
- 如果是网页本地存储或人工交接，按真实实现命名。它可以验证部分产品流程，不能标成MoneyAI跨会话记忆通过。
