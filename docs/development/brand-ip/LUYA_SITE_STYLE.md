# 路芽全站适配规范

版本：2026-08-28／品牌决定后的首份适配规范。**名称、现版 IP、理念与三页渐进方向已确认；下文具体配色、字号、措辞和布局方法为实施建议，最终 UI 尚未验收。**

依据：[当前决定](README.md)、[需求基线 REQ-25/26/28](../CURRENT_BRIEF.md)、[视觉简报](../demo/DESIGN_BRIEF.md)、[实施队列](../demo/IMPLEMENTATION_QUEUE.md)。适用于现有原生 HTML/CSS/ES modules，不新建工程或切换技术栈。

## 1. 已确认的产品表达

产品名：**路芽**。

产品理念：**把下一步看清楚，把每一次选择接起来。**

理念应体现为用户能做的事：说清当下情况、比较选择的条件和代价、拿到当前行动的内容，以及在有新情况时回看当时的决定。它不是每页重复的一段宣传语，也不表示保证增长、自动执行或永久记忆已经实现。

MoneyAI 继续承担分析、路径和历史决策的核心工作流。这是既定职责，不表示当前项目分析、历史写入与读回已经接通；各项按实际验证状态披露。品牌叙事不得将其弱化成装饰入口，也不能用角色的挎包代替真实写入、读回或模型验证。

## 2. 三页循序推进，不做默认专业控制台

用户已撤回 NotebookLM 三栏工作台作为主布局的建议。以用户描述的豆包式低上手成本、功能分隔与有序展开为方向；没有豆包截图或本轮实测，不能声称已复刻其界面。

每页只优先回答一个问题；少显示并列的工作面，但保留清楚的功能容器与其他信息入口。不要退回长回复平铺，不将三页收进同一聊天记录，也不靠巨型标题、缩小正文或隐藏风险腾空间。

| 页面 | 首先让用户完成 | 可继续浏览的具名入口（措辞为建议） | 始终保护 |
| --- | --- | --- | --- |
| P1 说清情况 | 主动开始语音或交材料，核对可修改摘要；手动入口默认折叠但可找到；一次只补问一个问题 | 改用文字输入、查看已交材料、修改这项情况 | 语音是否可用/是否发送、停止入口、转写与确认的区别、来源与未知、最多三问跨页共享 |
| P2 选择下一步 | 看到可选路径的简短比较、当前查看/已选状态、当前路径投入与风险，再明确选定 | 查看这条路的依据、查看其他路径、不同情况怎么选、下载路径报告 | 关键风险、重要未知、估计类型及依据摘要在选择前可见；查看/下载不改变选择 |
| P3 拿内容使用 | 找到所选行动的内容或步骤，预览并复制/导出 | 使用前核对、记录使用情况（选填）、返回查看路径 | 使用限制紧邻内容；复制/导出不等于采用或执行；反馈后置、失败与旧版本可见 |

### 渐进展示不取消浏览权

- 入口写出用途，不把依据、其他路径、历史和报告都藏进一个“更多”。
- 打开详情时明确当前看的路径、材料或内容；提供“返回路径比较”“返回当前内容”等可辨认返回方式。
- 返回保留当前浏览对象和未保存编辑，仍走现有导航/草稿守卫。输入改变后按已有版本失效规则处理，不能为了保持界面而继续使用过期分析。
- 关键风险、重要未知、真实来源与能力状态不能仅藏于详情或下载报告；精简的是重复说明，不是决策条件。
- 具名入口没有内容或接口时如实禁用/解释，不造空链接，不新增未获准的页面或导航模块。
- 路径数量、内容种类和补问来自本轮真实状态，不硬编码成演示中的两条路径、三个文件或固定三次提问。

### 每页的建议呈现方式

P1 采用一个主要讲述区域，收到内容后显示分组核对摘要；九组信息不变成一份必须逐项填完的长问卷。只对已有信息和必要缺口组织内容，保留可跳过与未知。语音权限、服务故障或提取失败时允许手动继续，不以预置文本冒充识别。

P2 以短路径列表/简明比较和当前路径为主，详细依据按需要展开；不要求用户同时理解资料库、聊天、分析和内容生产等三四个并列工作台。具体面板/抽屉/折叠形式需实际 PC 画面选择，不在本文冻结栏数。当前查看和已经保存的选择分开，主操作与状态相邻。

P3 保留内容选择、预览、就近取用和使用条件的明确区域；后置反馈可展开，不为品牌理念再加一段长解释。必要内容容器不因“减少 AI 感”取消。

## 3. 从现版路芽延续视觉语言

已查看原图中的暖白身体、深青绿芽冠与挎带、琥珀节点、柔和哑光外观。将其转化为温暖、清楚、克制的界面；不把整个网页做成玩具、毛绒材质或一排圆豆卡片。

建议保留现有浅色底与白色功能面；深青绿用于主操作、当前步骤与明确选中提示。琥珀少量点缀，不承担成功概率、结果好坏或“已经保存”的含义。没有为了“AI”加发光粒子、魔法徽章、假统计图或大段生成说明的需要；这也是后续约束，不意味着当前页面已存在这些装饰。

### 品牌与 IP 放置建议

- 公共壳以真实中文文字“路芽”为主，沿用现有三步导航；浏览器标题可统一为“说清情况 · 路芽”“选择下一步 · 路芽”“行动内容 · 路芽”，由统筹协调实际页面名称。
- 品牌理念只在合适的首次引导或品牌说明处使用，不占三页每个首屏的大标题。页面标题优先说当前任务。
- 现版 IP 保持不变。建议先静态、少量出现于起步或空态外围；不作为麦克风、提交、选路或成功状态按钮，不遮挡输入与内容。
- 静态使用是本任务建议，并非用户已批准新的姿态/动效规范；REQ-23 固定标题实施照常。
- 不把三视图整张铺进工作区，不用临时抠图、CSS 裁头像或重生图冒充完成的品牌标记。若需要单角色导出/透明素材，另核对文件适配方式与许可，不重开已定的造型选择。
- 原图入 Git 许可未确认时，先推进文字品牌、排版、主题和文案；不在网页引用私有审阅路径，也不扩大静态服务器范围暴露私有目录。

### 换色前必须处理的现有耦合

只读源码显示下列位置借用 --color-accent，不能做一次全局橙换绿就宣布适配完成：

- `demo/shared/base.css:23` 的通用 .status：信息、警告和错误要分别表达。
- `demo/pages/intake.css:339` 错误框边线及 `:560` 字段错误兜底。
- `demo/pages/decisions.css:77` error 边线、`:157` 路径风险边线。
- `demo/pages/action.css:404` 风险项目符号、`:795` warning 边线；warning 也可能承载保存等错误。

这些是待统筹与页面负责人处理的语义分工，不由品牌任务改代码。即使配色相近，也须保留文字、状态名称与键盘/读屏语义；品牌色、当前查看、已选定、执行和保存成功不是同一状态。

### 已完成的颜色算术检查

使用 sRGB 线性化、相对亮度和 (L亮+0.05)/(L暗+0.05) 计算。普通正文以 4.5:1、必要控件/状态可辨认的视觉信息以 3:1 作检查基线；具体例外及适用条件见 [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 与 [W3C 非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。

| 前景 / 背景 | 对比度 | 本轮有限结论 |
| --- | --- | --- |
| #243330 / #FFFFFF | 13.197:1 | 正文颜色组合通过算术检查 |
| #5F6B66 / #FFFFFF | 5.553:1 | 次文颜色组合通过 |
| #5F6B66 / #FAF9F6 | 5.275:1 | 暖白底次文组合通过 |
| #FFFFFF / #245E58 | 7.455:1 | 主按钮文字组合通过 |
| #7F8F87 / #FFFFFF | 3.397:1 | 控件边界组合通过 |
| #7F8F87 / #FAF9F6 | 3.227:1 | 暖白底控件边界组合通过 |
| #815914 / #FFF6E1 | 5.788:1 | 警示文字组合通过 |
| #AA2F2F / #FFF0ED | 5.999:1 | 错误文字组合通过 |
| #245E58 / #EDF4F0 | 6.674:1 | 选中区域文字组合通过 |
| #DDA64B / #FFFFFF | 2.181:1 | 仅点缀，不作为小正文或唯一功能线索 |
| #D9DED8 / #FFFFFF | 1.364:1 | 仅结构分隔，不作为唯一控件边界 |

数值是纯色计算，不是浏览器中透明度、叠层、字号、焦点遮挡或无障碍合规验收；也不是用户批准这些颜色的证据。

## 5. 中文与控件建议

维持现有中文系统字体回退，不下载外部字体。中文名称为主，暂不增加英文副品牌；字标保留为可访问文字，不生成新 logo。

- 正文建议 18px、行高约 1.6–1.7；按钮/标签可用明确设置的 16px，辅助说明优先 14px。不得靠缩到难读来达成首屏目标。
- P1 主标题建议 36–40px；P2/P3 的任务标题建议 28–32px、字重 600。具体值需真实中文与 PC 画面确认，不能把英文字体的负字距机械套给中文。
- 控件保持至少 44px 可操作区域和可见焦点；间距沿用共同的 8/16/24/32 节奏。
- 圆角建议控件约 10px、必要功能面约 12–14px；只在语音/描述的主要入口使用较柔和形态，不给每段文字独立包壳。
- 核对中文标点、长路径名称、69.90元、5MiB、时间与来源混排；不要把金额、单位、风险词拆成装饰小标签。
- 语音圆形入口服务于真实操作，可以保留；不以发光球或无限呼吸动画暗示后台正在监听。

以上是共同尺度建议，不要求三页用同一栏数、同一标题大小或重复同一套卡片布局。

## 6. 文案候选：去掉实现口吻，保留事实

下列原句在本轮只读源码复核时仍存在；建议句未实施。修改时保留 DOM 标识、状态、校验与测试含义，不通过文字缩短隐瞒能力边界。

| 当前原句 | 建议表达 | 来源与不能丢掉的含义 |
| --- | --- | --- |
| 像发一段语音一样，聊聊你的生意 | 可以从这几件事说起 | 01-intake.html:24；引出下方话题，避免重复主标题与按钮 |
| 我先确认一下，我有没有听懂你的生意 | 核对一下你的情况 | 01-intake.html:131；适用于语音和材料，仍保留未外部核实说明 |
| 展开完整业务树 | 不同情况，下一步怎么选 | 02-decisions.html:110；展开真实分支条件，不删决策树/报告内容 |
| 当前查看的路径 · 尚未通过本页操作选定 | 正在查看 · 这条尚未选定 | decisions.js:387；其他已保存选择仍须另显 |
| 选择尚未在共享状态中确认，停留本页以免误跳转。 | 还没确认这次选择已保存，请先留在本页。 | decisions.js:619；继续保留不确定性与导航守卫 |
| 手动选取 | 全选文字 | 03-action.html:73；处理函数只选预览文字，不等于复制成功 |
| 动作是否实施 | 这件事做了吗？ | 03-action.html:152；未知选项及执行/结果分离不变 |
| 空会话 · 尚未保存 | 这轮还没有保存内容 | shared/shell.js:78；读取失败仍单独显示，不能当成空记录 |

建议使用“先核对”“查看依据”“选择这条”“复制内容”等具体动词。没有数据依据时直说“目前还不能估计”，不要用拟人自信或抽象的智能结论补空白。

MoneyAI 来源、合成演示、材料发送范围、费用授权、未知、旧版本、错误、未保存与读回失败披露均保留。“少 AI 感”不是假装没有模型参与。

## 7. 动效边界

REQ-23 已授权每页一个固定标题的共享 FoldText；继续实施，不重新询问是否开工，也不以品牌化撤销。三页只接统筹的原生增强器，不安装 React/GSAP。

当前共有参数与回退以实施队列为准：一次播放、总预算不超过 800ms；副标题默认静态；减少动效、迟到或不适用条件静态回退。业务操作不等待标题动画，不能重新隐藏已可见的文字。

IP 本轮先静态是适配建议；不额外制造眨眼循环、漂浮、跳跃庆祝、逐段打字或全屏发光。输入、风险、动态路径名、估计数字、保存/错误状态保持直接可读；录音计时与任务等待只反映真实状态。

视觉反馈任务对 NotebookLM 官方 GIF 只看过首帧，品牌任务没有独立查看该 GIF；因此不将其作为动效评审证据。没有新增豆包画面或录屏，不宣称已测试其交互。

## 8. 集成顺序与待验

本任务仅交规范；统筹负责公共基线、壳、主题、实施排期和 Git，页面负责人只改自己的文件。品牌规范不成为 REQ-25 语音、第二页结构或第三页取用的开工门槛。

建议统筹先统一中文名称与状态语义，再协调共同 token/字体/控件；页面同时围绕三步目标调整信息顺序。导出报告若加品牌名，也须保留来源、假设、计算、版本与隐私白名单，不能用品牌装饰压掉依据。

下一次 PC 运行验收至少检查：

1. 1920×1080 下无需先理解专业后台，能看出本页要做什么、主操作在哪里；三页仍分开。
2. 其他信息入口有名字；有内容及接口的入口可进入、可返回，不可用时说明原因。返回不得静默丢失当前查看对象、选择或未保存编辑，用户经守卫明确放弃除外；输入改变时正确处理版本失效。
3. P2 选择前可见关键风险、重要未知、估计类型与真实来源；查看其他路径不改变已保存选择。
4. P3 先能预览与取用，反馈自愿且后置；全选、复制、导出、采用、执行、保存、读回分别反映真实事件。
5. 中文字形、长文、键盘焦点、控件状态、颜色对比与错误语义实际可辨；不能仅靠换绿确认完成。
6. FoldText 不妨碍操作、减少动效可回退；IP 不暗示监听、自动赚钱或记忆已接通。
7. 比较适配前后真实截图，至少检查布局、字号、配色、容器/间距与内容密度，并标明视口与状态。

这些均为待验判据。现版 IP 已定，不等于三页 UI、32/64px 图标、中文、语音、浏览器、MoneyAI 或经营效果已验收。
