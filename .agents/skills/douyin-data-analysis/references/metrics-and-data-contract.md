# 指标与数据口径

任何计算都先确定时间范围、观察窗口、数据粒度、分子和分母。指标名称相同但口径不同，应改名或分列。

## 推荐视频级字段

| 字段 | 必需性 | 说明 |
|---|---|---|
| `video_id` | 推荐 | 稳定唯一标识，避免标题相同导致重复 |
| `title` | 推荐 | 视频标题或内容摘要 |
| `publish_time` | 推荐 | 含日期、时间和时区 |
| `observation_window` | 推荐 | 发布后 24 小时、7 天或截至某日 |
| `content_type` | 分组时必需 | 由用户定义且全表一致 |
| `duration_seconds` | 留存时必需 | 视频总时长 |
| `views` | 基础分析必需 | 明确是播放次数还是去重观看人数 |
| `exposures` | 可选 | 若平台提供，用于曝光到观看分析 |
| `likes/comments/shares/favorites` | 互动时必需 | 缺少的分项不能默认为 0，除非确认就是 0 |
| `video_attributed_follows` | 视频转粉时必需 | 平台明确归因到该视频、且与播放量同一归因窗的关注数 |
| `profile_attributed_follows` | 主页关注时必需 | 明确由本组主页访问产生、且属于同一对象和归因窗的关注数 |
| `account_new_followers` | 账号增长时可选 | 同期账号新增关注，只用于账号周期变化；不能代替视频或主页归因关注 |
| `profile_visits` | 主页关注时必需 | 明确对象、去重口径和归因窗，并与 profile_attributed_follows 对应 |
| `completed_plays` | 实际完播时必需 | 完整播放次数或人数，需和 views 同口径 |
| `avg_watch_seconds` | 可选 | 平均观看时长，不等于完播次数 |
| `retention_3s/15s/...` | 可选 | 保留率或人数需写明单位 |
| `product_exposures/clicks/orders/buyers` | 商品转化时必需 | 每层记录商品或内容对象、人数或次数单位、归因窗和来源；只有相邻层级真实嵌套时才组成漏斗 |
| `traffic_source_*` | 来源分析时可选 | 各来源计数或占比 |
| `source_material_id/version/correction_chain` | 提取数据时必需 | 定位原材料、提取所用版本及后续更正，不用更正值覆盖原件 |

粉丝画像至少包含快照日期、粉丝总量和各分组计数或占比。竞品表还应包含采集来源、采集时间和公开可见范围。

## 核心公式

### 播放与相对表现

- 平均播放量 = 总播放量 ÷ 视频数。
- 中位播放量 = 排序后的中间值，通常更能代表典型视频。
- 相对表现指数 = 单条视频播放量 ÷ 可比视频中位播放量。
- 播放增长率 = `(本期 - 上期) ÷ 上期 × 100%`；上期为 0 时不计算百分比，只报告绝对变化。

“爆款”应定义为账号内部的相对表现，例如高于同观察窗口历史中位数若干倍或位于前 10%。阈值由样本分布和业务习惯确定，不把固定倍率当平台通用规则。

### 互动

- 综合互动数 = 点赞 + 评论 + 分享 + 收藏，具体包含项必须列明。
- 单视频互动率 = 综合互动数 ÷ 播放量 × 100%。
- 分项率 = 对应互动数 ÷ 播放量 × 100%。
- 多视频总体互动率 = 全部综合互动数之和 ÷ 全部播放量之和 × 100%。
- 典型视频互动率 = 各视频互动率的中位数。

总体互动率和视频互动率均值回答的问题不同。前者受大播放视频权重影响；后者让每条视频权重相同。优先报告总体率与中位数，并说明用途。

### 完播、观看与留存

- 实际完播率 = 完整播放次数或人数 ÷ 同口径播放次数或观看人数 × 100%。
- 平均观看时长占比 = 平均观看时长 ÷ 视频时长 × 100%。
- 某节点保留率 = 到达该节点的人数 ÷ 起播人数 × 100%。
- 区间流失率 = `(上一个节点人数 - 当前节点人数) ÷ 上一个节点人数 × 100%`。

平均观看时长占比不是实际完播率。重播可能让观看时长占比超过 100%，不得静默截断。平台只提供平均观看时长时，应明确写“观看时长占比”，不能改名为完播率。

### 转粉与商品漏斗

- 视频播放到关注率 = 该视频归因关注人数 ÷ 同一视频、同一归因窗的去重观看人数 × 100%。
- 主页访问到关注率 = 由这组主页访问归因的关注人数 ÷ 同一对象、同一归因窗的主页访问人数 × 100%。
- 同期账号新增关注只用于账号增长描述；除非平台提供可核验归因，不得除以某条视频播放或主页访问并命名为转化率。
- 商品曝光到点击率 = 归因到该商品或内容曝光的点击人数 ÷ 同对象、同归因窗的商品曝光人数 × 100%。若只能用观看人数作分母，且点击确实归因到这些观看，名称改为“观看到点击率”。
- 商品点击到下单率 = 归因到这组点击的下单人数 ÷ 同对象、同归因窗的商品点击人数 × 100%。只有订单次数时，应报告“每次点击对应订单数”等事件比率并说明可能重复，不能冒充人数转化率。
- 观看到购买率 = 归因到这组观看的购买人数 ÷ 同对象、同归因窗的去重观看人数 × 100%。

计算任何转化率前必须同时满足：分子属于分母覆盖的人群或事件、对象一致、归因窗一致、人数与次数单位可比。商品点击、订单与购买人数若无法证明层级嵌套，应分列为独立指标并标明不可拼漏斗。不同漏斗层级不可共用“转化率”一个名字，报告必须写清起点和终点。

### 粉丝和竞品变化

- 粉丝增长率 = `(期末粉丝 - 期初粉丝) ÷ 期初粉丝 × 100%`。
- 分布占比 = 分组人数 ÷ 有效样本人数 × 100%。
- 集中度可用 TOP3 分组占比之和描述；没有必要为小样本引入复杂指数。
- 差距倍数 = 竞品指标 ÷ 己方指标，仅在分母大于 0 且口径一致时使用。

## 比较规则

1. 生命周期一致：不要拿发布 2 小时的视频和发布 30 天的视频直接比累计播放。
2. 内容可比：按内容类型、时长、目标和账号阶段做分组或控制。
3. 时间一致：节假日、活动期和普通周分开标记。
4. 样本量可见：每个组都显示 `n`；样本很少时只写方向，不写稳定规律。
5. 分布优先：播放量偏态时用中位数、四分位数或分位排名辅助均值。
6. 外部基准有出处：记录来源、日期、适用行业、样本和指标定义；不满足时只作背景，不评级。

## 数据质量检查

- 唯一键是否重复；
- 同一列是否混用计数和百分比；
- 缺失值是“没有采集”还是“真实为 0”；
- 互动分项是否覆盖同一观察窗口；
- 转粉和商品漏斗的分子是否属于分母，且对象、归因窗和人数／次数单位一致；
- 数据导出后账号是否发生补量、删除或口径更新；
- 分组占比总和是否接近 100%，四舍五入误差单独说明；
- 竞品数据是否来自同一工具或可校准来源；
- 隐私字段是否已删除或最小化。
- 提取值是否保留材料 ID、版本和更正链，并与商家自述、原件、派生计算、公共参考和情景假设分开。

无法确认的数据用 `未知` 或 `未提供`，不自动填 0。
