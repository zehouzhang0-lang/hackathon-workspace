# 经核验的直播话术组件

本参考用于起草直播话术。它提供表达结构而非商业事实；任何花括号字段都必须有用户确认、平台记录或可核验来源，缺失时保留待核验，不进入可口播版本。

## 一、逐句核验表

| 字段 | 所需依据 | 核验要点 | 未核验时处理 |
|---|---|---|---|
| 商品名称与规格 | 商品页、包装或商家资料 | 型号、容量、材质、数量、适用范围 | 删除该陈述或标待核验 |
| 商品特点 | 可定位的产品资料 | 条件、限制、是否属于敏感作用描述 | 只描述已确认部分 |
| 价格与优惠 | 当前商品页或活动配置 | 适用对象、时间、结算条件、时间戳 | 不口播具体价格或优惠 |
| 库存与发货 | 当前库存及履约记录 | 更新时间、地区、预计发货条件 | 引导以页面实时状态为准 |
| 赠品与促销 | 已确认活动规则 | 数量、资格、限制、兑现方式 | 不承诺赠送或优惠 |
| 抽奖与互动活动 | 当前官方规则及完整活动方案 | 资格、奖项、选择、公示、兑现 | 不生成参与号召 |
| 第三方评价或身份 | 可授权使用的原始证明 | 内容真实性、授权范围、有效期 | 不引用 |
| 售后与保障 | 当前公开政策 | 适用条件、期限、例外 | 引导查看正式政策 |

平台页面可能实时变化。价格、库存和活动信息应记录核验时间，并提示以用户实际结算页面和正式规则为准。

## 二、开场与议程

适合在不制造压力的前提下说明本场内容：

- 「欢迎来到直播间。今天会依次介绍{已确认商品或主题}，有问题可以随时留言。」
- 「这场会重点讲{已确认范围}，我会把适用情况和限制一起说明。」
- 「如果你正在比较{用户场景}，可以先听完规格、使用条件和售后信息，再决定是否适合。」

不要使用无法证明的优惠力度、购买人数或活动结果吸引停留。

## 三、商品介绍

按“是什么 → 适合谁 → 已确认特点 → 限制 → 如何核对”组织：

- 「这是{商品名称与规格}，主要面向{已确认适用场景}。」
- 「资料中确认的特点有{特点}，对应的使用条件是{条件}。」
- 「需要注意的是{限制或不适用情况}。」
- 「关于{尚未确认问题}，现有资料不足，我先不作承诺；确认后以商品页或正式说明为准。」

对健康、安全、性能或结果类陈述，应同时说明证据范围和适用条件。没有合格依据就不口播。

## 四、价格、活动与购买信息

只有核验表完整时才可使用：

- 「当前页面显示的价格是{价格}，适用于{对象和条件}，有效信息截至{核验时间}；最终以结算页为准。」
- 「已确认的活动条件是{活动规则}，包括{限制与兑现方式}。不符合条件时不适用。」
- 「库存和发货状态会变化，请以商品页实时信息及客服确认为准。」

不要把比较价写成原价，或把阶段性条件描述成长期承诺。不要引用后台人数、销量或库存变化来制造购买压力。

## 五、互动与问答

- 「大家最想先了解规格、使用条件还是售后？我按问题顺序回答。」
- 「你问到的是{问题}。目前已确认的是{事实}；仍需确认的是{未知}。」
- 「这个情况与个人需求有关，可以对照{已确认条件}判断，不合适也不需要勉强购买。」
- 「我先记录这个问题，核验后通过{已确认的公开渠道}补充，不在现场猜测。」

互动活动只有在规则、奖项、选择和兑现均核验后才能写入执行稿，并应完整说明条件。

## 六、投诉与风险反馈

涉及质量、安全、价格差异、履约或售后时，停止销售劝导，先确认事实并给出正式处理路径：

- 「谢谢你指出这个问题。我先记录具体情况，请不要在公屏发送订单号、电话或地址。」
- 「如果涉及使用安全，请先停止使用，并通过{已确认售后渠道}联系处理。」
- 「你反馈的页面价格与口播不一致，我们以实际结算记录为准并立即核对；未核清前不继续引用该价格。」
- 「这项问题目前没有足够信息判断，我不会现场下结论；请通过{公开客服或售后渠道}提交必要资料。」

区分正常质疑、售后问题和骚扰。正常问题应回应或转交，不得为了维持节奏而掩盖。

## 七、异常应对

| 情况 | 建议表达与动作 |
|---|---|
| 商品暂不可购买 | 说明当前状态未知或暂不可用，停止相关介绍，核验后再恢复 |
| 价格信息不一致 | 立即更正，说明以结算记录为准，并撤回未核验表述 |
| 商品信息答不上来 | 明确待核验，不猜测，不用相似商品信息代替 |
| 网络或设备异常 | 如实说明暂停，恢复后复述可能遗漏的重要条件 |
| 安全或售后投诉 | 停止销售引导，保护个人信息，转入正式处理流程 |

## 八、收尾

- 「今天确认过的信息我已经讲完，未确认的问题会按刚才说明的渠道补充。」
- 「购买前请再核对商品页的规格、价格条件、发货和售后信息，按自己的需要决定。」
- 「感谢大家提出问题，涉及订单或个人信息请通过正式客服渠道处理，不要发在公屏。」

## 九、占位字段规则

| 占位字段 | 必须记录 |
|---|---|
| {商品名称与规格} | 原始资料位置和版本 |
| {特点 / 条件 / 限制} | 证据范围与敏感类目检查 |
| {价格 / 活动规则} | 来源、适用对象、有效期和核验时间 |
| {库存 / 发货} | 数据来源、地区和更新时间 |
| {售后渠道} | 可公开访问的正式渠道 |
| {观察指标} | 定义、分子、分母、对象和窗口 |

本参考不提供任何商业事实的替代内容。字段无法核验时，宁可缩短稿件，也不要补写。
