# 大战黑客松

本仓库用于本次黑客松的项目资料、开发代码与进度记录，便于在不同设备之间继续工作。

## 当前状态

当前优先选择第 5 题“抖音做了不出单，怎么办”，工作名称为 **抖音成交诊断 Agent**。

核心流程：录入经营资料，提出有证据支持的优先问题，记录行动，再结合历史数据复诊。

目前仅完成赛前方案整理，尚无应用代码；官方题目认领、比赛限制、MoneyAI 能力、首个行业案例和团队分工仍需确认。

## 从这里开始

- [项目进度](PROGRESS.md)：记录当前阶段、已完成事项、待办和重要决定。
- [产品方案](docs/PRODUCT_BRIEF.md)：定位、六项能力、证据约定、记忆设计和待确认规则。
- [Demo 验收与排期](docs/DEMO_ACCEPTANCE.md)：最小演示流程、验收条件和建议安排。
- [多设备同步指南](docs/SYNC.md)：首次下载项目，以及切换设备时如何拉取与推送。

## 工作约定

- 每次开工先拉取最新内容，结束时更新进度、提交并推送。
- 重要决定和后续任务写入 `PROGRESS.md`，避免只保留在聊天里。
- API 密钥、令牌、密码和真实的 `.env` 文件不进入仓库；需要时只提交不含秘密的配置示例。
- 技术方案确定后，再补充代码目录、安装步骤和运行说明。
