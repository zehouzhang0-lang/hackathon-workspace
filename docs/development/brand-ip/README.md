### 取代哪些旧说法

- REQ-26 取代“正式名称/IP 尚待选择”；首轮私有评阅中的未选状态属于历史，不再据此要求重选、重画或先完成外审 P0。
- REQ-28 撤回 NotebookLM 三栏专业工作台作为主布局的建议。借鉴用户描述的豆包式易上手与信息组织，不照搬配色、界面或功能；没有取得新的豆包截图，不要求像素复刻。
- 保留三页：**语音说清情况 → 看清并选择下一步 → 拿到内容并使用**。不合并成一页聊天，也不扩展成专业控制台。
- “减少 AI 感”落实到具体中文、明确动作和克制装饰；不隐瞒 MoneyAI、演示来源、重要未知、风险、失败或保存边界。

## 如何接续

1. 统筹按[实施队列](../demo/IMPLEMENTATION_QUEUE.md)保护语音入口与三页功能优先级，审阅本目录规范后统一安排公共壳、主题和页面应用。
2. 品牌与“视觉反馈与动效评审”任务对齐意见，不直接向三个页面派活。结构参考服务于路芽流程，不另起主题。
3. 1920×1080 PC 先行；手机后置。没有新的 Figma 创建授权，不创建手机稿或新文件。既有获准只读参考不等于最终视觉。
4. Browser 可信路径问题按统筹当前通道约定处理；不静默改信任或改用 Playwright。颜色计算、截图和业务实测分别记录。
