### 取代哪些旧说法

- REQ-26 取代“正式名称/IP 尚待选择”；首轮私有评阅中的未选状态属于历史，不再据此要求重选、重画或先完成外审 P0。
- REQ-28 撤回 NotebookLM 三栏专业工作台作为主布局的建议。借鉴用户描述的豆包式易上手与信息组织，不照搬配色、界面或功能；没有取得新的豆包截图，不要求像素复刻。
- REQ-30 覆盖旧语音独占主入口、手动折叠、九组主展示和自由另选布局的建议；P3增加同页反馈后改判状态，旧规范不再作为完整功能清单。
- 公共三步统一为**资料确认 → 找到优先问题 → 执行并记录**；“反馈后改判”是P3内状态，不新增第四页，不合并成一页聊天。
- “减少 AI 感”落实到具体中文、明确动作和克制装饰；不隐瞒 MoneyAI、演示来源、重要未知、风险、失败或保存边界。

## 当前 IP 的使用边界

本任务已实际打开的现版路芽为 1536×1024 RGB PNG，包含三视图、背景和接触阴影，无透明通道。文件版本 SHA-256：

`bfc991211593c9a8f96d611aa2b8f1421c479009b829129ade65c5258c3d467f`

采用现版不等于透明单角色资产、图标、动画或三维工程已完成。保持造型、配件与现有形象，不按首轮外审建议改眼、改左右或扭转芽冠。本轮不生图、不裁图、不复制图片。

用户已确认现版用于本项目；**原图入私有 GitHub 的许可仍单独核对**。没有把 ZIP、其他候选、外部审计原文、私人路径或原图复制进本目录或公开设计资产目录。选图不等于商标、近似形象或使用权审查通过；也不自动授权对外发布、第三方上传或收费调用。

## 如何接续

1. 现任统筹“路芽开发统筹接续”按[REQ-30 功能锁定](../demo/WIREFRAME_FUNCTION_LOCK.md)与[实施队列](../demo/IMPLEMENTATION_QUEUE.md)统一公共壳、共享能力和页面应用；本任务仅交品牌／文案约束。
2. 品牌与“视觉反馈与动效评审”任务对齐意见，不直接向三个页面派活。结构参考服务于路芽流程，不另起主题。
3. 1920×1080 PC 先行；手机后置。没有新的 Figma 创建授权，不创建手机稿或新文件。既有获准只读参考不等于最终视觉。
4. Browser 可信路径问题按统筹当前通道约定处理；不静默改信任或改用 Playwright。颜色计算、截图和业务实测分别记录。
