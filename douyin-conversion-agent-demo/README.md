# 抖音成交实验 Agent Demo

线上抖音实物电商的老板可理解成交决策流黑客松演示版本。

## 当前能力

- 默认进入老板模式，按“是／否／不确定”一步一问完成一次成交实验。
- 使用React Flow显示只读成交决策路径，绿色表示走过、黄色表示当前节点。
- 电脑端左侧看路径、右侧回答问题；窄屏先回答问题、再查看路径。
- 原输入、分析、输出三栏完整保留在“专业详情”，供评委和操盘人员核验。
- 输入一个商品、统一时间窗、数据来源和五段成交漏斗。
- 对合成、商家脱敏导出和公开真实数据分别标注证据边界。
- 计算播放、点击、加购、创建订单和支付四段转化率。
- 先做数据质量检查，再用确定性规则锁定一处优先实验断点。
- 自动路由内容承接、商品利益点、信任疑问或交易阻力Skill。
- 输出事实、待验证假设、A/B路径和可直接使用的成交材料。
- 生成含主指标、护栏、最低样本、观察周期、停止和回滚的实验处方。
- 保存采用、拒绝、经营限制和实验结果，生成不同的第二轮建议。
- 通过独立MoneyAI sidecar调用Codex总控推理。
- MoneyAI或Codex失败时保留本地质检、断点、Skill路由和实验处方。

## 三类内置验收场景

| 场景 | 预期断点 | 专家Skill |
| --- | --- | --- |
| 内容点击断点 | 播放到商品点击 | 内容承接 Skill |
| 商品信任断点 | 商品点击到加购 | 信任与疑问 Skill |
| 支付交易断点 | 创建订单到支付 | 交易阻力 Skill |

所有内置场景均为合成数据，只用于验证产品流程。

## 运行

前置条件：本机已安装 MoneyAI-Agents（桌面端已启动），BFF 后端已就绪。

终端零（可选，真实推理与长期记忆需要）：启动 BFF 后端（见 `douyin-backend/README.md`）：

```bash
cd douyin-backend && npm install && npm start
```

- BFF 在线（live）：页面经 BFF 编排 MoneyAI 生成，老板反馈同步沉淀进 MoneyAI 长期记忆。
- BFF mock 模式：返回契约演示结果，页面明确标注「Mock演示模式」，不冒充真实推理。
- BFF 未启动：页面回退本地可信模式，质检、断点、Skill路由与实验处方照常运行。

终端二，启动网页：

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://127.0.0.1:4173
```

## 事实边界

- 默认三个场景和漏斗数字均为合成演示数据。
- 公开真实电商数据只能验证算法，不能冒充真实抖音商家经营数据。
- 页面显示的断点由保守演示规则排序，只用于决定下一项实验，不是行业因果结论。
- MoneyAI只负责执行已路由Skill并生成假设与成品，不能覆盖本地锁定的质检、断点和事实。
- 浏览器反馈记忆使用版本化localStorage，尚未写入MoneyAI Memory。
- 页面不承诺订单、GMV、ROI或成交率增长。
